マニュアル追加ガイド

新しいマニュアルを追加する際の手順と設計方針

📌 マニュアル追加フロー

  1. このHTMLファイルの const manuals = [...] 配列に新エントリを追加する
  2. id（連番）、title、category、tag、ver、date、content を記入する
  3. contentの中にh3・step-list・alert-boxを使ってマニュアル本文を記述する
  4. バージョン番号のルールに従ってverを設定する（例：v1.1.0）
  5. バージョン履歴ビューにリリースノートを追記する
  6. ファイルを保存してチームに共有する
✅ HTMLは単一ファイルなので、Slackやメールで共有するだけで全員が最新版を使えます
⚠️ 更新前に必ず旧バージョンのファイルをバックアップとして保存してください
マニュアルデータの書き方（テンプレート）
{
  id: 10,                          // 連番ID
  title: "マニュアルのタイトル",
  category: "問い合わせ対応",       // カテゴリ名
  tag: "inquiry",                  // inquiry / refund / fraud / spec
  ver: "v1.1.0",
  date: "2025-08-01",
  content: `
    <h3>セクションタイトル</h3>
    <p>説明文...</p>
    <ol class="step-list">
      <li>手順1</li>
      <li>手順2</li>
    </ol>
    <div class="alert-box alert-warn">⚠️ 注意事項</div>
  `
}
