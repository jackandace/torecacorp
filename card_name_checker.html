カード名点検ツール

card テーブルの登録名を確認 → 修正対象を選択 → 反映用SQLを書き出し
1. データを取り込む
Supabase の結果を CSV ダウンロード、または下に貼り付け（CSV / TSV / JSON）
取り込み用SQL（Supabase SQL Editor で実行 → CSV ダウンロード） 
-- 列名の確認（初回のみ）
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_schema='public' AND table_name='card'
ORDER BY ordinal_position;

-- 全カード抽出（排出実績つき・読み取りのみ）
SELECT c.id,
       c.name,
       c.product_number,
       c.card_category_id,
       c.image_url,
       COUNT(g.id)      AS gift_count,
       MAX(g.granted_at) AS last_granted_at
FROM card c
LEFT JOIN gift g ON g.card_id = c.id
GROUP BY c.id, c.name, c.product_number, c.card_category_id, c.image_url
ORDER BY c.card_category_id NULLS FIRST, c.name;
