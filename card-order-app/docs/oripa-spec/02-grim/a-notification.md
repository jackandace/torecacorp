## 1. 全体像

GRIMアプリのヘッダー右上に **通知ベル 🔔** を設置（未読時は赤丸バッジ）。
ベル押下で **通知ページ** を開き、上部の **タブナビゲーション（3タブ）** で切り替える（オリパワン準拠）。

| タブ | 名称 | 中身 | 配信 | 既読 |
|------|------|------|------|------|
| ① | **あなたへの通知** | 配送・ポイント・ランクアップ・招待特典・個別・(コイン有効期限) | アクション時に自動送信 | 通知単位 |
| ② | **チャージ** | 課金時の詳細内容（決済明細） | 決済完了時に自動送信 | 通知単位 |
| ③ | **お知らせ** | キャンペーン・イベント・誤表記訂正・その他（運営告知） | 管理画面から手動配信 | ユーザー×お知らせ単位 |

> オリパワンのレイアウト: ヘッダー（ロゴ＋通貨＋🔔）→ 直下に横タブ → 各タブはフルページのリスト
> （`時刻（薄字）` ＋ `本文` の2段。お知らせは右端に `>` で詳細ページへ）→ 最下部にページャ。

---

## 2. 通知タイプ定義

### ① あなたへの通知（`tab = personal` / 自動送信）

| type | ラベル | 発生トリガ | 本文例 | 主な metadata |
|------|--------|-----------|--------|---------------|
| `shipping` | 配送通知 | 発送ステータス更新 | 商品を発送しました（追跡番号: …） | tracking_no / carrier / order_id |
| `point_granted` | ポイント付与 | ポイント付与時 | 500ポイントを付与しました | amount / reason |
| `rank_up` | ランクアップ | ランク昇格時 | **ゴールドに昇格！ 500P獲得（還元率 3%→5%）** | new_rank / granted_points / point_rate |
| `invite_bonus` | 招待特典付与 | 招待成立時 | 招待特典として1,000ポイントを付与しました | reward / invitee |
| `coin_expiry` | コイン有効期限 ※ | 期限切れ前日／当日（バッチ） | 198コインの有効期限が明日切れます／切れました | amount / expire_at |
| `individual` | 個別のお知らせ | 管理画面から個別送信 | （任意テキスト） | sent_by_admin |

> ※ `coin_expiry` はオリパワンに存在する通知。**GRIMのコインに有効期限がある場合のみ**有効化（→ §9 要確認）。

### ② チャージ（`tab = charge` / 自動送信）

| type | ラベル | 発生トリガ | 本文例 | 主な metadata |
|------|--------|-----------|--------|---------------|
| `charge_complete` | 課金時の詳細内容 | 決済完了時 | クレジットカードで1,000コイン(1,030ランクポイント)をチャージしました | amount_yen / coins / rank_points / method / payment_id |

> GRIM要件の「課金時の詳細内容」をオリパワン同様 **チャージ専用タブ** に分離。

### ③ お知らせ（`category = broadcast` / 管理から手動配信）

| type | ラベル | 例 |
|------|--------|----|
| `campaign` | キャンペーン情報 | 夏の大感謝キャンペーン開催！ |
| `event` | イベント情報 | 限定オリパイベント開始 |
| `correction` | 誤表記・訂正のお知らせ | 【訂正】排出内容表記の誤りについて |
| `other` | その他お知らせ | メンテナンス終了のお知らせ |

> お知らせは **詳細ページ**（例: `/news/:id`）を持ち、一覧では右端に `>`。本文長文・画像可。

## 3. 機能要件

1. **ヘッダー右上に 🔔 ベル**（全ページ＝マイページ上部含む）。未読 > 0 で **赤丸バッジ**（件数、`99+` 頭打ち）。
2. ベル押下で **通知ページ**へ。上部に **［あなたへの通知｜チャージ｜お知らせ］** の横タブ。既定はあなたへの通知。
3. 各タブはフルページのリスト（新しい順）。`時刻＋本文` の2段表示。お知らせは `>` で詳細へ。
4. **未読/既読を管理**。各タブに「すべて既読にする」。タップで既読化＋遷移。
5. リストは **ページネーション**（オリパワン同様の番号ページャ）または無限スクロール。
6. **①②は自動送信**（個別のお知らせ `individual` のみ管理から手動）。**③は管理画面から手動配信**。
7. **保持期間**（§5）。

---

## 4. 未読件数（ベルの赤丸バッジ）

ベルのバッジ件数は、**あなた向け未読**（①あなたへの通知＋②チャージのうち、まだ既読にしていないもの）と、**全体向け未読**（公開中のお知らせのうち、まだ既読にしていないもの）の合算とする。

- いずれも**保持期間内**のもののみを対象とする（①②は保持期間を過ぎたものは数えない、お知らせは表示終了したものは数えない）。
- タブ別の未読数（タブ見出しの小バッジ）も、各タブ分を同様の考え方で算出する。

---

## 5. 保持期間

| 対象 | 保持 | 根拠 |
|------|------|------|
| ① あなたへの通知 / ② チャージ | **1ヶ月（31日）** | クライアント回答「1ヶ月想定」 |
| ③ お知らせ | **長期保持（実質アーカイブ）** | オリパワンでも数ヶ月前のお知らせが閲覧可。ニュース履歴として残す |

- ①②は日次で、発生から31日を過ぎたものを自動削除する。
- お知らせは任意の表示終了日時で表示を制御。一覧は基本的に削除しない（運用で非表示化）。
- ※ ①②もタイプ別に保持を変えたい場合は設定値化可能（要望時）。

> 「1ヶ月想定」は **あなたへの通知/チャージ** に適用。お知らせ（運営告知）は長期保持を推奨 → §9 で要確認。

---

## 6. 自動送信（①②）

各アクションの成功直後に、対応する通知を自動生成する。どのアクションでどの通知が出るかは以下の通り。

| アクション | 生成される通知 |
|-----------|----------------|
| 発送済 | ①あなたへの通知に「配送通知」（追跡番号などを差込） |
| ポイント付与 | ①あなたへの通知に「ポイント付与」（付与額・理由を差込） |
| ランク昇格 | ①あなたへの通知に「ランクアップ」（新ランク・獲得ポイント・還元率を差込） |
| 招待成立 | ①あなたへの通知に「招待特典付与」（特典内容・招待相手を差込） |
| 決済完了 | ②チャージに「課金時の詳細内容」（金額・コイン・ランクポイント・決済手段などを差込） |
| コイン期限前日 | ①あなたへの通知に「コイン有効期限」（対象コイン量・期限を差込）※有効化時 |

## 7. 管理画面（コンソール）

### 7-1. ③お知らせ 配信
- 種別（キャンペーン/イベント/誤表記・訂正/その他）・タイトル・本文（長文/画像）・配信日時（即時/予約）・表示終了（任意）。
- プレビュー → 配信。詳細ページ（`/news/:id`）自動生成。
- 配信履歴（日時/種別/配信数/開封率）。

### 7-2. ①個別のお知らせ 送信
- 宛先: 個別ユーザー検索 / **セグメント**。＋ **任意テキスト**（タイトル・本文）＋遷移先。
- **セグメント絞り込み条件**（複数条件はAND・送信前に対象人数の概算を表示）:
  - **ガチャIDで絞り込み**: 指定ガチャを利用（抽選）したことがあるユーザーが対象。
  - **直近ログインN日以内**: 指定日数以内にログインしたアクティブユーザーが対象。
  - 既存のランク/属性（例: ゴールド会員）とも組合せ可。
- ①②の自動通知（配送・ポイント・ランク・課金等）は **送信履歴の閲覧** が中心。

---

## 8. ユーザー画面（オリパワン準拠 / GRIMブランド）

- ヘッダー: 王冠ロゴ／レインボーキー🔑／コイン（G）／**🔔ベル（赤丸）**。※マイページ（プロフィール）はフッターメニューにあるため、ヘッダーには置かない（重複を避けスッキリさせる）。
- 通知ページ: 横タブ［あなたへの通知｜チャージ｜お知らせ］。アクティブはゴールド下線。
- リスト各行: `2026年5月30日 00:12`（薄字）＋ 本文。区切り線。
- お知らせ行は右端に `>`（詳細ページへ）。
- 最下部にページャ（`1`）。空状態は「通知がありません」。
- ランクアップ例: 「ゴールドに昇格！ 500P獲得（ポイント還元率 3% → 5%）」。

## 9. 確認事項

| # | 確認点 | 暫定対応 |
|---|--------|---------|
| A | 未読/既読管理 | **対応済**（①②は通知単位の既読、③はユーザー×お知らせ単位の既読）。バッジは3タブ合算。 |
| B | 保持期間 | ①②=**1ヶ月(31日)**で確定。③お知らせは**長期保持**を推奨（要承認）。 |
| C | チャージタブの範囲 | 「課金時の詳細内容」を割当（決済完了明細）。チャージボーナス等も含めるか要確認。 |
| D | コイン有効期限通知 | オリパワンにあり。**GRIMのコインに有効期限があるか**で要否確定（→なければ削除）。 |
| E | ベル設置位置 | グローバルヘッダー右上（=マイページ上部含む全ページ）。マイページ専用にするなら変更可。 |

## 10. テスト観点

- [ ] ヘッダーに🔔、未読時に赤丸バッジ（3タブ合算）
- [ ] あなたへの通知／チャージ／お知らせ の3タブ切替
- [ ] お知らせ行の `>` で詳細ページ遷移
- [ ] 各アクションで①②が自動生成（発送/ポイント/ランク/招待/課金）
- [ ] ランクアップ通知に新ランク・獲得P・%が差し込まれる
- [ ] `individual` を管理から任意テキスト送信
- [ ] ③を管理から配信→全ユーザーのお知らせに反映、既読管理
- [ ] タブ単位「すべて既読」、バッジ減算
- [ ] ①②の31日自動削除、お知らせは長期保持
- [ ] 他人宛の①②が見えない
