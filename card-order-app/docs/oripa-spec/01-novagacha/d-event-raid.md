## 0. 依頼（Yu.様）

> 「レイドイベントもできますか？ **消費コイン数に応じてボスHPを削って、倒したら貢献度によって高還元ガチャを回せる**ようにする感じです！」

**→ 実現可能。** 全ユーザー共有のボスをコイン消費で攻撃し、討伐後は **貢献度に応じた高還元ガチャ** を解放する設計とする。
高還元ガチャの「アクセス制御」は既存 [01-b BTロック解放](b-bt-unlock-gacha.md) の解放の仕組みを **貢献度ベース** に応用できる。

---

## 1. ゲームフロー

```
① レイド開催（ボス出現、HP=最大）
② ユーザーがコインを消費して攻撃 → 消費コイン量に応じてボスHPを削る
③ 攻撃ごとに「貢献度（与ダメージ累計）」を記録
④ 全体の累計ダメージでボスHPが0 → 討伐成功
⑤ 討伐時、貢献度（ティア）に応じて 高還元ガチャ を解放（回せる回数を付与）
⑥ ユーザーは解放された高還元ガチャを回して報酬獲得
（⑦ 次ボス/次ステージへ。マルチステージ運用も可）
```

---

## 2. コア仕様

### 2-1. 攻撃＝ダメージ
- **与ダメージ = 消費コイン × ダメージ係数**（既定 1.0、管理設定）。
- 攻撃手段（要確認 §5-A）:
  - **案A（推奨）**: レイド専用ガチャを回す＝コイン消費＝ダメージ＋通常景品も獲得。
  - 案B: ボスへ直接「攻撃」（コイン消費のみ、景品なし）。
- いずれも消費コイン分を当該ユーザーの累計貢献度に加算する。

### 2-2. ボスHP
- ボスは **全ユーザー共有のHP** を持つ（合算ダメージで減少）。
- HP=0で `defeated`。以降の攻撃は不可（または次ステージへ）。

### 2-3. 貢献度と報酬解放
- **貢献度 = ユーザーの累計与ダメージ**。
- 討伐時、貢献度 **ティア** に応じて高還元ガチャの **解放（回せる回数）** を付与。

| ティア例 | 累計ダメージ | 高還元ガチャ回数 |
|----------|--------------|------------------|
| Gold | 100,000以上 | 10回 |
| Silver | 50,000以上 | 5回 |
| Bronze | 10,000以上 | 1回 |
| 参加賞 | 1以上 | （任意：少量BT等） |

- ティア境界・回数・対象ガチャは **管理画面で設定**。
- 解放された高還元ガチャは **コインで回す**（01-bと同様、解放＝アクセス権付与）。

---

## 3. 攻撃・討伐ロジック

- 攻撃時はイベント開催中かつボスが討伐前であることを確認する。
- 与ダメージ = 消費コイン × ダメージ係数（小数は切り捨て）として算出する。
- コインを消費する。残高不足の場合は攻撃を受け付けずエラーを返す。
- ボスの残HPからダメージを差し引く。残HPは0未満にはせず下限でクランプする（オーバーキル分は無効）。
- 実際にHPへ反映されたダメージ（クランプ後）を、その攻撃の貢献度として当該ユーザーの累計に加算する。
- 同時攻撃が競合してもHPがマイナスにならないよう、HPの減算はアトミックに行う。
- 同一の攻撃が二重に集計されないよう冪等に処理する（同じ攻撃の再送は加算しない）。
- 残HPが0になったらボスを討伐済みとして確定し、以降の攻撃は受け付けない。
- 討伐確定時点の各ユーザーの累計貢献度を基準にティアを判定し、ティアに応じて対象の高還元ガチャを回数付きで解放する（解放処理は非同期でもよい）。

---

## 4. ユーザー画面（イベントページ）

- **ボスビジュアル＋HPバー**（残HP / 最大HP、全体進捗%）。
- **自分の貢献度**（累計ダメージ）＋現在ティアと、次ティアまでの目安。
- **貢献ランキング**（上位＋自分）。
- **攻撃導線**（レイド専用ガチャ or 攻撃ボタン）。
- **討伐演出**（HP0でボス撃破モーション）。
- 討伐後: **「高還元ガチャ ○回 解放中！」** バナー → 高還元ガチャへ。

---

## 5. 管理画面

- レイド作成（type=raid）: 名称・期間・バナー。
- ボス設定: ステージ・ボス名/画像・最大HP。
- ダメージ係数（コイン→ダメージ）、攻撃モード（ガチャ/直接）。
- 貢献ティア（境界ダメージ・解放回数）、報酬（高還元）ガチャ指定。
- 進行状況（残HP・参加者数・貢献ランキング）の監視、手動討伐/延長等の運用操作。

## 6. 未確定事項

| # | 確認点 | 暫定 |
|---|--------|------|
| A | 攻撃手段（専用ガチャ消費 / 直接攻撃） | 専用ガチャ消費（景品も出る）を推奨 |
| B | ダメージ式（コイン1=1ダメージ等） | `damage = coins × 係数`（係数=1.0既定） |
| C | 討伐報酬の解放は回数制 or 期間制 | 回数制（remaining_spins）。期間制が良ければ変更 |
| D | マルチステージ/周回の有無 | ステージ対応で設計（単一でも可） |
| E | 未討伐で期間終了時の扱い | 参加者へ参加賞 or 報酬なし、を要確認 |
| F | 高還元ガチャの還元率上限・在庫 | 既存ガチャ設定に準拠 |

## 7. テスト観点
- [ ] コイン消費でボスHPが係数通り減る
- [ ] 同時攻撃でHPがマイナスにならない（アトミック・クランプ）
- [ ] 貢献度が正しく累計される、二重加算なし（冪等）
- [ ] HP0で討伐確定、以降攻撃不可
- [ ] 貢献ティア判定通りに高還元ガチャが回数付きで解放される
- [ ] 解放回数を消費して高還元ガチャを回せる、0回で不可
- [ ] コイン残高不足で攻撃不可
- [ ] 期間外は攻撃不可、未討伐終了時の扱いが仕様通り
