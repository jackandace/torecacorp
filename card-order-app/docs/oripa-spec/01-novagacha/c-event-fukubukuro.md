## 1. 概要

期間中に **ポイントを獲得して順位を競う** ランキングイベント。
上位入賞者に **NOVA BAG（福袋）＋BT** を付与する。

> 添付バナー「2026年6月度 福袋争奪戦」準拠。開催期間 **2026/6/11 〜 6/15**。

---

## 2. ポイント獲得方法（バナー準拠）

| 行動 | 獲得ポイント |
|------|-------------|
| **S賞 獲得** | **50 pt** |
| **A賞 獲得** | **20 pt** |
| **B賞 獲得** | **10 pt** |
| **課金 500円ごと** | **0.5 pt** |

- 賞獲得ポイントは **ガチャ抽選で当該ランクの景品が確定した時** に加算（1枚ごと）。
- 課金ポイントは **決済完了額** に対し `500円 = 0.5pt`（按分。例: 1,000円→1.0pt、300円→0.3pt ※端数処理は §6-A）。
- C賞以下・その他ランクは対象外（＝0pt）。対象ランク・レートは **管理画面で変更可能**。

---

## 3. ランキング報酬（バナー準拠）

| 順位 | NOVA BAG（福袋） | BT |
|------|------------------|----|
| 1位 | 100,000コイン相当 | +100 BT |
| 2位 | 50,000コイン相当 | +50 BT |
| 3位 | 50,000コイン相当 | +30 BT |
| 4〜6位 | 30,000コイン相当 | +15 BT |
| 7〜10位 | 15,000コイン相当 | +10 BT |

- **NOVA BAG（福袋）** = 指定コイン相当の特別景品（福袋）。付与方法は §6-B で要確認（福袋景品として付与 / コイン換算付与 など）。
- BTは確定後にウォレットへ付与。
- 順位区間・報酬は **管理画面で設定可能**（順位レンジ＋報酬内容）。

---

## 4. ポイント加算ロジック

開催中（active 期間）のみ加算。各処理の成功後にアトミックに反映する。

- **賞確定時**: 対象ランク（S/A/B）の景品が確定したら、当該ランクの獲得ポイントを加算する（S=50 / A=20 / B=10）。
- **決済完了時**: 決済額に応じて課金ポイントを加算する（500円ごとに0.5pt、按分。端数処理は §6-A）。
- **冪等性**: 同一の抽選・決済が二重加算されないように、参照元の識別子で重複を防止する。
- **連続抽選**: 10連/100連は当選ランクごとに加算する（S×n + A×m …）。

---

## 5. ランキング・報酬付与

### 5-1. ランキング表示
- ユーザーには **自分の順位＋ポイント** と **上位ランキング** を表示する（リアルタイム/準リアルタイム）。
- **タイブレーク**: 同ポイントは **先に到達したユーザーが上位** とする。

### 5-2. 確定・付与（イベント終了時）
1. イベント終了でポイント加算を停止し、最終ランキングを確定する（スナップショット保存推奨）。
2. 順位レンジに従い、該当ユーザーへ **NOVA BAG＋BT** を付与し、付与履歴を記録する。
3. （通知基盤があれば）報酬付与通知を送信する。
4. クローズ状態へ移行する。

> 11位以下は報酬なし。同点で10位が複数の場合の扱いは §6-C で要確認。

## 6. 未確定事項

| # | 確認点 | 暫定 |
|---|--------|------|
| A | 課金ポイントの端数処理（500円未満の扱い） | 按分（300円=0.3pt）。切り捨て運用なら変更 |
| B | NOVA BAG（福袋）の付与方法 | 福袋景品として付与（コイン相当は表示価値）。コイン直接付与なら変更 |
| C | 同点で報酬ボーダー（10位）に複数 | 全員に当該報酬付与 or タイブレークで打ち切り、を要確認 |
| D | 対象ランク（S/A/B）固定か、ガチャ別に可変か | 全イベント共通設定（管理で変更可） |
| E | 不正・キャンセル時のポイント減算 | 決済キャンセル時はログ打ち消し（マイナス加算）を想定 |

---

## 7. 管理画面

- イベント作成（type=ranking）: 名称・期間・バナー画像。
- **ポイント設定**: S/A/B 賞 pt、課金レート（円→pt）、対象ランク。
- **報酬設定**: 順位レンジ（1 / 2 / 3 / 4-6 / 7-10 …）ごとに NOVA BAG コイン相当・BT 数。
- 進行中ランキングの閲覧、終了→報酬付与の実行、付与履歴。

---

## 8. テスト観点
- [ ] S/A/B 賞確定でそれぞれ 50/20/10pt 加算
- [ ] 課金500円ごとに0.5pt（端数仕様通り）
- [ ] C賞以下は加算されない
- [ ] 10連/100連で当選ランク数に応じ加算
- [ ] 同一draw/paymentで二重加算されない（冪等）
- [ ] ランキング順位・自分の順位が正しい、同点タイブレークが効く
- [ ] 期間外は加算されない
- [ ] 終了後、順位レンジ通りにNOVA BAG＋BTが付与される
- [ ] 決済キャンセルでポイントが打ち消される
