# 要件定義書｜ガチャ演出 裏ボタン（確定音・GOGOランプ）

> クライアント共有用。**設計・実装方式（DB/API等）は含めません**（実装担当が設計）。
> 構成: ①想定している挙動 ②重要キーファンクション（必達） ③補完要件（イレギュラー対応） ④デザイン要件（mockで確認）

| 機能ID | クライアント | 対象画面（stg実機） |
|--------|------------|---------------------|
| 01-f | ノヴァガチャ様 | 演出画面／マイページ／（管理）ガチャ演出・オリパ編集 |

---

## ① 想定している挙動

ガチャの**演出画面**に「**裏ボタン**」を追加。演出中に画面のボタン（タップエリア）を押すと、
**当選している場合に確定音が鳴り、GOGOランプが点灯**する（パチスロの確定演出的な“ドキドキ”体験）。

**想定シーン**
1. ガチャを引くと演出（ネオンチューブのリール）が再生される。
2. 演出中、画面に**タップできるエリア**が出る（スキップボタンのようなイメージ）。
3. タップすると、**当たっている場合に確定音**が鳴り、**下部のGOGOランプが点灯**する。
4. 音に気づけなくても、ランプ点灯で当たりが分かる。

> 「確定音」＝鳴ったら当選確定の示唆。**ハズレでは絶対に鳴らない**（誤示唆を出さない）。

---

## ② 重要キーファンクション（必達）

- **ガチャごとに裏ボタン演出のON/OFF**を設定できること。
- **当選している場合のみ確定音が鳴る**こと（ハズレ・対象外では鳴らない）。
- 確定音の対象を**賞ランク（既定A賞以上、ガチャ別に設定可）**で制御できること。
- 確定音の**出現確率**を設定でき、**タップを契機に**発火すること（毎回必ず鳴る仕様にしない＝レア感）。
- 確定音と同時に**GOGOランプが点灯**すること（マナーモード・消音でも視覚で判別可能）。
- マイページに**演出モード設定（ON/OFF）**があり、OFFで裏ボタン演出を無効化できること。

---

## ③ 補完要件（イレギュラー対応）

| 想定シーン | あるべき挙動 |
|-----------|-------------|
| タップ連打 | 確定音を**多重再生しない**（1演出で1回） |
| 対象外当選（閾値未満）・ハズレ | 何回タップしても鳴らない（**誤示唆ゼロ**） |
| マナーモード／消音 | **GOGOランプ点灯**で当たりが分かる |
| 演出モードOFF | タップエリア・確定音・ランプを一切出さない |
| 10連・100連の演出 | 対象となる当選（最上位等）を基準に判定（基準は要確認） |
| 当落の事前バレ・改ざん | 当落判定は**ユーザー操作で先読みできない**こと（鳴る/鳴らないが操作前に露見しない） |
| 演出スキップ | 既存のスキップは**従来通り**動作する |

## ④ デザイン要件（mockで確認）

- 演出画面（全画面）に **タップエリア（透明オーバーレイ）** を重ね、**下部にGOGOランプ**。
  - 実機の演出画面 右側に**既存の円形リングランプが2基**あり、これを発光させてGOGOランプとする案が低コスト。
- 確定音は**複数種類**を登録・選択可（重要度は低く、まず1種→将来複数でも可）。
- マイページに**演出モード設定**項目を追加。
- 既存のダークネオンUI・トークンに準拠。スキップ表示は維持。

**管理画面（実機構成に準拠）**
- 「ガチャ演出」は**動画マスタ**（`/gacha_effects`）。ここに**確定音（音源）**を同様に追加。
- 「オリパ編集」に**裏ボタン演出 ON/OFF・対象賞ランク・出現確率・タップ毎確率・確定音選択**を追加。賞ランク S/A/B/C/D/その他 は既存を流用。

**確認用mock**
- 機能モック（ユーザー画面）: [機能モック.html](../../mocks/裏ボタン/機能モック.html)（演出／確定音発火／マイページ設定）
- 管理画面制御: [管理画面制御.html](../../mocks/裏ボタン/管理画面制御.html)（裏ボタン演出ON/OFF・対象賞・確率・確定音）
- 実画面の演出: [nova-actual-screens.html](../../mocks/nova-actual-screens.html)（⑥演出画面）

## 要確認（クライアント）
- 確定音方式: 「タップ毎に1/Nで抽選」（ドキドキ重視）／「対象なら初回タップで確定」（簡易）どちらか。
- 10連・100連での判定基準（最上位当選を対象 等）。
- 確定音の複数種類は初期から必要か（後追いでも可）。
