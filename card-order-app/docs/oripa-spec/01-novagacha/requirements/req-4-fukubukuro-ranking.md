# 要件定義書｜争奪戦：福袋争奪戦（ランキングイベント）

> クライアント共有用。**設計・実装方式（DB/API等）は含めません**（実装担当が設計）。
> 構成: ①想定している挙動 ②重要キーファンクション（必達） ③補完要件（イレギュラー対応） ④デザイン要件（mockで確認）
> ※「争奪戦」は **本書（福袋争奪戦＝ランキング）** と [対抗戦（レイド）](req-3-taikousen-raid.md) の2種を含む。

| 機能ID | クライアント | 設置先 |
|--------|------------|--------|
| 01-c | ノヴァガチャ様 | イベントスペース内の福袋争奪戦ページ／管理は新規イベントメニュー |

---

## ① 想定している挙動

期間中に **ポイントを貯めて順位を競う**イベント。上位入賞者に **NOVA BAG（福袋）＋BT** を付与する。

**想定シーン**
1. イベント開催（例: 6/11〜6/15）。イベントページにポイント獲得方法・順位報酬・自分の順位・ランキングが表示される。
2. ユーザーがガチャで **S/A/B賞を獲得**、または **課金**するとポイントが貯まる。
3. 期間中、順位はリアルタイムに更新される。
4. 期間終了時に順位が確定し、上位入賞者に報酬が付与される。

**ポイント獲得（バナー準拠・管理で変更可）**
| 行動 | pt |
|------|----|
| S賞獲得 | 50 |
| A賞獲得 | 20 |
| B賞獲得 | 10 |
| 課金 500円ごと | 0.5 |

**順位報酬（同）**
| 順位 | NOVA BAG（福袋） | BT |
|------|------------------|----|
| 1位 | 100,000コイン相当 | +100 |
| 2位 | 50,000コイン相当 | +50 |
| 3位 | 50,000コイン相当 | +30 |
| 4〜6位 | 30,000コイン相当 | +15 |
| 7〜10位 | 15,000コイン相当 | +10 |

---

## ② 重要キーファンクション（必達）

- **S/A/B賞の獲得**と**課金**でポイントが**正しく加算**されること（賞別pt・課金レートは管理で設定可）。
- 期間中の**順位とポイントがユーザーに見える**こと（自分の順位＋ランキング）。
- 期間終了時に**順位を確定**し、**順位レンジ別の報酬（NOVA BAG＋BT）を付与**できること。
- ポイント加算は**イベント期間内のみ**有効であること。
- 順位レンジ・報酬内容は**管理画面で設定**できること。

---

## ③ 補完要件（イレギュラー対応）

| 想定シーン | あるべき挙動 |
|-----------|-------------|
| 同点が複数いる | タイブレークを定義（**先に到達したユーザーが上位**）。表示・報酬判定で一貫させる |
| 10連・100連での獲得 | 当選した賞ランクの**数だけ**加算（S×n＋A×m…） |
| 同一の抽選・決済が二重に処理 | **二重加算しない**（1抽選・1決済＝1回のみ） |
| 決済キャンセル/返金 | 付与済みポイントを**打ち消す**（不正な順位上昇を防ぐ） |
| 報酬ボーダー（10位）に同点多数 | 取り扱いを定義（全員付与／タイブレークで打ち切り）※**要確認** |
| 期間外のアクセス | 「開催前／終了」を表示し、加算しない |
| 課金ポイントの端数（500円未満） | 端数処理を定義（按分: 300円=0.3pt 等）※**要確認** |
