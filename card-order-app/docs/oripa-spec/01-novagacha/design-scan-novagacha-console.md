## 5. オリパ編集フォーム（全項目・実測）

> 4機能の管理設定はこの画面が中心。

- オリパ名 / カテゴリ名（ポケモン・ワンピース・デュエマ・MTG・BT専用ガチャ・Dev）
- ヘッダー画像（ファイル選択＋プレビュー）
- **オリパタイプ**：通常 / 抽選 / 確率（※**新規作成時のみ**変更可能）
- **消費タイプ**：選択してください / **ポイント / バッテリー / 課金消費** ← 機能1・4の核
- 消費量
- ガチャ条件：条件無し / 1日1回 / 1回限定
- ガチャ回数設定：1回 / 10連 / 100連（トグル）
- レベル制限：全てのレベル
- 通常バッテリードロップ率（%）
- 当選結果を非表示（トグル）
- 公開/非公開 / 公開予定日 / タイマー表示 / タイマー開始日時 / 公開終了日
- **景品**：**S / A / B / C / D / その他** の各ランクごとに、**当たり演出**（標準S〜／インベーダー演出【虹/金/赤/緑/青/白】）・カード・状態・個数・表示形式
  - カード状態：普通 / PSA10 / PSA10アウトレット / 未開封 / CGS / 傷あり
  - 合計枚数上限 50,000枚
- 特典：キリ番賞 / ラストワン賞 / **ウォンテッド賞**（対象賞・対象カード・演出・報酬カード）
- ボーナスオリパ（消費量・最大回数・一人当たり最大回数）
- 保存

## 7. NOVA新機能（4点）の管理画面 追加先マッピング

| 機能 | 追加先（管理） | 具体 |
|------|----------------|------|
| **課金限定ガチャ BT消費タイプ**（機能1） | オリパ編集の「消費タイプ」 | 現状は単一選択（ポイント/バッテリー/課金消費）。**「課金消費」かつ「BT消費」で回せる**よう、消費リソース指定を拡張（課金消費時の消費＝コイン/BTを選べる等）。消費量はBT数として解釈 |
| **裏ボタン**（機能2） | ガチャ演出 ＋ オリパ編集 | ガチャ演出マスタに **確定音（音源）** を追加（動画と同様にメディア管理）。オリパ編集に「裏ボタン演出 ON/OFF・対象賞ランク（S/A/B…）・出現確率・タップ毎確率・確定音選択」を追加。賞ランクS/A/B/C/D/その他は既存を流用 |
| **BT消費解放ガチャ**（機能3） | オリパ編集 | 「BTロック ON/OFF・必要BT数」を追加。ロック中はフロントで解放ブロック表示 |
| **争奪戦**（機能4） | **新規「イベント」メニュー**（現状なし） | イベント作成（期間・バナー・ポイント配分・順位報酬 等）。フロントのイベントスペースと対応。※現コンソールにイベント管理は未実装＝新規追加 |

---

## 8. 既存の前提（新機能追加にあたって）
- **消費タイプにバッテリー/課金消費が既存** → 機能1はゼロからではなく既存選択肢の組合せ拡張。
- **賞ランク S/A/B/C/D/その他 が確立** → 争奪戦のpt付与・裏ボタンの対象賞に流用可能。
- **演出は動画マスタ＋ランク割当の仕組みが既存** → 裏ボタンの確定音もこの仕組みに乗せられる。
- **イベント管理メニューは未実装** → 争奪戦・対抗戦は新規メニューが必要。
- バックエンドSupabase／UIはChakra → 新規画面も同スタックで実装すれば整合。
