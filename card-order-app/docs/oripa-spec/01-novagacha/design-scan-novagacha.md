# NOVA GACHA UIコンポーネント／デザイン情報整理（stg実機スキャン）

| 項目 | 内容 |
|------|------|
| 対象 | stg-novagacha-frontend（`https://stg-novagacha-frontend.vercel.app/`） |

## 1. 技術スタック（判明分）

| 区分 | 内容 |
|------|------|
| UIフレームワーク | **Tailwind CSS + DaisyUI**（`:root` に DaisyUI テーマ変数 `--p/--s/--a/--n/--b1/--bc` 等を確認） |
| コンポーネントテーマ | DaisyUI 既定テーマ相当（primary=violet, secondary=magenta, accent=teal） |
| フォント | **M PLUS 1p**（Google Fonts） |
| 配信 | Vercel（SPA / クライアントルーティング） |
| ボタン規則 | `--btn-text-case: uppercase`、`--rounded-btn: 0.5rem`、フォーカス時 scale 0.95 |

> コンポーネント＝DaisyUI標準スタイル、**世界観（背景・バナー・演出）＝独自のダークネオン/サイバー**を上に重ねる構成。

| **抽選マシン** | ガチャ詳細の中央UI。1/10/100ガチャの円形ネオンボタン |

## 6. 新規仕様（01-a〜01-f）の実画面マッピング

| 仕様 | 追加先の実画面 | 実装メモ |
|------|----------------|----------|
| **01-a BT消費ガチャ** | `/box/:id` 抽選マシン＋確認ダイアログ | 「N コイン」表示を「N BT」に切替。残高ピルはヘッダーのBTを参照。確認ダイアログ文言も切替 |
| **01-b BTロック解放** | `/box/:id`（ガチャ詳細） | ロック時は抽選ボタンを「BTで解放」に差し替え、解放確認ダイアログ→解放後コイン抽選。一覧カードに🔒バッジ |
| **01-E イベントスペース** | `/?tab=battery`（現バッテリー交換所） | 現状は交換カードのみ。ここをイベント常設ハブ化（イベントバナー＋交換所を内包）。メインタブ名称見直し |
| **01-c 福袋争奪戦** | イベントスペース内の新ページ | ランキングUI（pt獲得方法・順位報酬・自分の順位）。配色は既存ネオンに準拠 |
| **01-d レイドイベント** | イベントスペース内の新ページ | ボスHPバー・貢献度・討伐→高還元ガチャ解放。解放は01-bの仕組み流用 |
| **01-f 裏ボタン** | **演出画面**（全画面オーバーレイ） | 既存のネオンチューブ演出に「タップエリア（透明）」を重ね、下部にGOGOランプ。右側の既存リングランプを流用/拡張する案あり。スキップは維持 |
| 演出モード設定（01-f） | `/me` メニュー | 現状メニューに無いため新規追加（裏ボタン演出 ON/OFF） |

> ※ 本書はNOVA専用。GRIM様の機能（通知・レインボーキー等）はNOVAには含めない。

> **重要な気づき**: 演出画面の右側には既に「円形リングランプ」が2基あり、01-fのGOGOランプはこれを発光制御する形で自然に統合できる可能性が高い（新規ランプ追加より低コスト）。

## 7. 既存の状態（新機能追加の前提）
- マイページのメニューに **演出モード設定は未実装**（＝01-fで新規追加）。
- バッテリー交換所は **交換カードのみの最小構成**（イベント拡張余地大）。
- コイン以外に **バッテリー／金バッテリー** の通貨が既に存在（BT消費・BT解放・イベント報酬と整合）。
- 通貨の **失効期限** 概念が既にある（BT消費の消費順ルールに関係）。

## 8. 補足
- コンポーネントはDaisyUI標準のため、新規UIも **DaisyUIクラス＋既存ネオン装飾** で実装すれば整合が取りやすい。
- 配色は §2 のトークンをそのまま使用可能（primary=#570DF8 / secondary=#F000B8 / accent=#2BCDBE、面=#0E0F1A）。
