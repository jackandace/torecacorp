# GRIM layout alignment

Reference: https://jackandace.github.io/torecacorp/grim-renewal/ (observed 2026-09-08).

Observed catalog: 220px desktop sidebar + 960px content, separate header/category navigation, independent sorting controls. Reference detail and member pages: 760px centered column; collection: 1120px with 3 desktop columns and a fixed bottom action area. Adopted those widths, with a compact 64px desktop header and one category row (Ori Parade has no Super parent category).

Ori Parade keeps its orange action color, rounded Japanese typography, original P coin, existing routes, ranks and sample wallet. No GRIM-only hashtags, RUSH, JP, Super catalog, season pass, collection filters or other unverified features were added. Existing five Ori Parade sorts are retained.

Catalog campaigns moved below the products; duplicate campaign links removed. Draw buttons remain 1/10/100 with a prepaid sample wallet. Detail retains conditions, prize ranks, centered special prizes, and original caution content. Member page is a single column with compact rank summary, coin balance, boost, shortcuts, and account settings. Collection actions are fixed below the cards; sample exchange/shipping eligibility stays unchanged.

Verified in browser: 1440px desktop and 390px mobile, no document horizontal overflow; categories end before sort begins; 760px detail/member, 1120px collection; mobile rank table fits its container; selecting an eligible card enables shipping; 10-draw button preselects 10 in confirmation. No live payment, real draw, or real shipping was performed.
