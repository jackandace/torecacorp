# 表示機能の照合 — 2026-09-08

## 結論
実機能を参考にしたデザインプレビューだが、全表示が既存仕様の忠実な再現ではなかった。今回、根拠のない機能追加を取り除いた。バックエンド接続済み、全条件検証済み、全機能完成とは扱わない。

## 今回削除・修正
| 表示 | 判定と対応 |
|---|---|
| 注目のオリパ／100コインで選ぶ | こちら独自のフロント絞り込み。実サイトに一致する操作を確認できず削除 |
| 固定の「注目のオリパ」「PICK UP!」 | 登録済みタグではなく編集上の付加。非表示だったマークアップを含め削除 |
| 未読件数／すべて既読にする／未読ドット | お知らせ管理は存在するが既読管理は記録・現物で確認できず削除 |
| チケットの「使えるガチャを探す」 | 実際には券種による絞り込みをしていないため「オリパ一覧へ」に変更 |

今後は管理設定または実画面で確認できた機能だけを利用者画面に出す。プレビュー用のサンプルデータ・画面遷移と、本体の実処理を区別する。
