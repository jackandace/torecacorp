D. 文法の軸ルール

音文法
ミュートでも成立する設計を優先
視覚の確定合図を主軸に置く
カメラ文法
ズーム / スロー / 振動で熱量を作る
音に合わせてカメラを動かす
カットS　Hook / 導入 〜3秒
優先：テンポ ＞ 最小ブランド
目的：離脱・スキップされない掴み
やること：祭壇出現 → 封印核（署名）浮遊・静止
やらないこと：署名提示以外すべて禁止
カットM　示唆 6〜8秒（+3〜5秒）
優先：期待 ＞ テンポ ＞ ブランド ＞ 脳汁
目的：期待・熱さを上げる
やること：ベル合図 → 円環+ルーン出現 → 回転+ヒビ示唆 → カットL or XLへ
やらないこと：長い前兆・フェイント・キャラ本体登場・強そうな要素・逆転多用・最上位別表現（虹核/二重刻印）
カットL　発展なし確定 / ハズレ 8〜12秒（+2〜4秒）
優先：テンポ最優先
目的：発展なしで気持ちよく確定
演出：封印核破断 → 白確定表示 → 結果UIへ
やらないこと：確定前の長い溜め禁止
カットXL　チャンスアップ 11〜15秒（+5〜7秒）
優先：脳汁 ＞ 期待 ＞ ブランド ＞ テンポ
目的：脳汁スイッチ。終了 or 発展
やること：破断直前+チャンスアップ部品。記念カット（スクショ映え）・SNS映え1ポイント必須
やらないこと：強い煽り後の弱結果・「破断っぽいのに破断しない」連発
カットE　発展あり確定 / 祝福 16〜22秒（+5〜7秒）
優先：脳汁最大 ＞ ブランド記憶 ＞ 祝福 ＞ テンポ
目的：当たり価値の最大増幅
演出：ベル → 激しい円環+ルーン → 強ヒビ+光 → 破断 → 色確定 → Celebrate → 結果UIへ。祝福は確定後に厚く。記念カット必須。
やらないこと：Eで確定しない・確定前の長い溜め禁止

カットM
通常SE

アケルの役割定義

封印解除のカードパック妖精。解放者・ユーザーの味方
手/装置/司会役＝「解除の起点」を作る存在
レアなときのみ本体が出演（声/ベルを鳴らすなど）

「解放」の物語ライン

貼られている → ヒビが入る → 光が漏れる → 解放

演出の5つの役割

期待
当たりが近い「感じ」を段階で作る。M/XLが主戦場
報酬強化
当たりのうれしさを増幅。XLが主戦場（Mでやりすぎない）
テンポ
気持ちよく次に回したくさせる。Mが主戦場。スキップは最初から可
ブランド体験
世界観/キャラ/トーンを記憶させる。Sで署名表示、Mで記憶に焼く
信頼（最重要）
「強さの表現」をカット階層で制限する。誤解されやすいが最重要

質感の統一ルール

封印は「割る」に固定
見た目：パック封印核 + 封印シール + 光 + 亀裂（背景固定）
光の出方：亀裂から漏れ出す光の強さで示唆
レア度の文法は「封印状態」で表現（色は後付け）
著作権譲渡不可の場合、以下の条件をすべて契約に明記することが必須
A
永続的な利用（期限なし）
サービスが継続運用・長期前提のため。期限付きライセンスは不可
B
改変・編集・再構成が可能
チャンスアップ追加・尺/構成/演出順の変更・一部差し替えが将来的に確実に必要なため
C
二次利用・商用利用が可能（媒体追加）
LP・告知ページ・SNS・広告・将来の別UIなどで使うため
D
第三者への再委託（再許諾）が可能
制作者が変わる前提（依頼が難しくなるケースを加味）。別会社への改修/追加制作依頼のため
E
著作者人格権の不行使
改変・再委託に対する後のトラブル防止。「その改変は想定外」などの後からの主張変更を防ぐため
F
第三者素材の条件
BGM/SE/フォント/プラグインが再委託不可だと全体が詰むため。使用素材は「商用利用可・改変可・二次利用可・再委託可」をすべて満たすこと。素材一覧とライセンス条件の明示が必須
G+H
本件成果物の扱いと再利用禁止
本件向けに制作・加工したすべての素材/エフェクト/UIは成果物扱い。映像・演出構成・素材の他案件転用は禁止（ノウハウ/スキルの再利用は可）
I
制作元データ・素材の取り扱い
制作・使用した素材/音源/プロジェクトは、契約で定めた納品物以外に第三者提供禁止
