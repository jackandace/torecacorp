# winc-anime

MUSCAT GROUP様（WinC様）向け ガチャ演出アニメーション「型② 一撃フリーズ（カウントダウン演出）」の検討資料です。

| ファイル | 内容 |
|---|---|
| `index.html` | 参考2案（ハラキリ系／からくり系）の比較。シーン展開の絵コンテ、参考画像と使うシーン、15分岐の整理、構成パーツ、必要素材 |
| `vcon.html` | 仮Vコン（9/25版）。世界観3案の切り替え、分岐の再生、分岐ごとの仮絵コンテ |

## 見方
ブラウザで `index.html` を開くだけで表示できます（外部ファイル不要）。
GitHub Pages では、`https://jackandace.github.io/torecacorp/winc-anime/` で見られます。


## 注意
- 参考画像は演出の方向性をすり合わせるための資料です。絵柄・キャラクター・文字は制作物に使用しません。
- 仮Vコンの分岐構成は9/25時点のものです。最新の15分岐は `index.html` の「15分岐の整理」を参照してください。
