## 1. はじめに

このシステムは PALETTE GROUP トレカ商事カンパニーから商品を **卸価格で発注**するための専用システムです。

### 推奨環境
- **PC**: Chrome / Safari / Firefox の最新版
- **スマートフォン**: iOS Safari / Chrome (一部画面は PC 推奨)

### ログイン情報
- 管理者から **招待メール**が届いたら、リンクをクリックしてパスワードを設定してください
- ログイン URL: <https://card-order-app-v2.vercel.app/login>

## 2. ログイン・パスワード

### 2-1. ログイン
1. <https://card-order-app-v2.vercel.app/login> にアクセス
2. **メールアドレス**と**パスワード**を入力
3. **ログイン**ボタン

ログイン成功すると自動でマイページへ移動します。

### 2-2. パスワードを忘れた場合
1. ログイン画面下部の「**パスワードを忘れた方**」をクリック
2. 登録メールアドレスを入力
3. メールで届くリンクから新しいパスワードを設定 (8 文字以上)

### 2-3. パスワード変更
ログイン後、**プロフィール**ページ → 「パスワード変更」セクションから変更できます。

## 3. 発注する

ヘッダーの **発注** をクリックして発注フォームを開きます。

### 3-1. 商品を探す

**検索ボックス** / **カテゴリタブ** / **ソート** で絞り込めます:

- **検索**: 商品名・型番で部分一致 (例: `ポケモン`, `PK-SV2A`)
- **カテゴリ**: すべて / ポケモン / ワンピース / その他
- **ソート**: 締切が近い順 / 新着順 / 価格安い順 / 価格高い順

### 3-2. 締切バッジ

商品カードに付くバッジで締切までの時間が一目でわかります:

| バッジ | 意味 |
|---|---|
| 🟢 灰 (締切 XX-XX-XX) | 8 日以上 |
| 🟡 黄 (あと N 日) | 4〜7 日 |
| 🟠 琥珀 (あと N 日) | 1〜3 日 |
| 🔴 赤 (本日締切 / 締切超過) | 急ぎ |

### 3-3. カートに追加

各商品カードで:
1. **BOX** または **CT** を選択
2. 数量を入力
   - **BOX**: 最低 **12 BOX** から
   - **CT**: 最低 **1 CT** から (1 CT = 12 BOX が標準)
3. **カートに追加** ボタン

右側のカートに反映され、小計が自動計算されます。

### 3-4. 発注リクエスト送信

1. カート内の商品・数量を確認
2. **免責事項・キャンセル不可規約に同意します** にチェック
3. **リクエスト送信** ボタン
4. 確認モーダルで内容を最終チェック → **送信する**

> ⚠ **送信後はキャンセルできません**。内容に誤りがないか必ず確認してください。

### 3-5. 発注後の流れ

1. **リクエスト** ステータスで担当者に連絡が行く
2. **発注調整中 / 仮確定** で数量が決まる (カット割の場合)
3. **確定** で最終確定 → 出荷準備
4. 確定後に **請求書発行** → 入金 → 発送

各ステップでメール通知が届きます。

## 4. マイページ

ヘッダーの **マイページ** をクリック。

### 4-1. KPI カード (上部 3 つ)

| カード | 内容 |
|---|---|
| 現在のランク | プラチナ / ゴールド / シルバー / ブロンズ / スタンダード + リベート率 |
| 今月の発注額 | 仮確定 + 確定の合計 |
| 次ランクまで | 不足金額 |

### 4-2. ランク進捗バー

次ランクへの進捗をビジュアル表示。グラデーションバーで現状の達成率がわかります。

### 4-3. 発注履歴

過去の発注を一覧表示 (10 件ずつページ送り)。

- **ステータスタブ**で絞り込み (リクエスト / 発注調整中 / 仮確定 / 確定 / キャンセル)
- 行クリックで **詳細モーダル**が開く:
  - 商品名・希望数量・確定数量
  - 案内掛け率・リベート率
  - 金額試算 (小計 / リベート / 課税対象額 / 消費税 / 合計)
  - 追跡番号 (発送済の場合)

### 4-4. 請求書履歴

過去の請求書を一覧表示。

- ステータス: 未入金 (赤) / 一部入金 (琥珀) / 入金済み (緑)
- 行クリックで **詳細モーダル**:
  - 請求書番号・発行日・支払期限
  - 金額内訳
  - **PDF をダウンロード** ボタン

### 4-5. ボタン (下部)
- **発注ページへ** — 発注フォームへ
- **通知履歴** — 通知一覧へ
- **発注履歴 CSV** — 自分の発注全件を CSV ダウンロード

### 4-6. ランク制度

| ランク | 月次発注額 (昇格基準) | リベート率 |
|---|---|---|
| プラチナ | ¥1,000,000 以上 | 10% |
| ゴールド | ¥500,000 以上 | 7% |
| シルバー | ¥200,000 以上 | 5% |
| ブロンズ | ¥100,000 以上 | 3% |
| スタンダード | — | 0% |

- **昇格**: 翌月 1 日に即時昇格
- **降格**: 昇格基準の 50% を下回ると 1 ヶ月猶予後に 1 ランク降格
- 自動更新タイミング: 毎月 1 日 0:00 (UTC)

リベートは請求書発行時に自動適用されます。

## 5. プロフィール管理

ヘッダーの **プロフィール** から:

### 5-1. アカウント情報 (読み取り専用)
- メールアドレス / ランク / 状態 / 登録日

> メールアドレス・ランク・状態の変更は管理者にお問い合わせください。

### 5-2. 基本情報の編集
- 会社名・屋号 / 担当者 / 電話 / 登録住所 / 配送先住所

変更したら **保存** ボタン。

### 5-3. パスワード変更
- 新しいパスワード (8 文字以上) + 確認用
- **パスワードを変更** ボタン

### 5-4. 宣誓書

- 提出済みなら緑バッジで提出日・失効日を表示
- 未提出なら黄色バッジ
- PDF を選択 → **アップロード**

> 失効日は管理者が確認後に設定します。

## 6. お問い合わせ・FAQ

### 6-1. FAQ (よくある質問)

ヘッダーの **FAQ** から。カテゴリ別に折りたたみ表示。

質問をクリックして展開、回答を読めます。

### 6-2. お問い合わせ送信

ヘッダーの **お問い合わせ** → **新規問い合わせ**:

1. **カテゴリ**: 商品 / 発注 / 請求書・入金 / 発送 / アカウント / その他
2. **関連商品** (任意): 該当商品を選択
3. **件名** (必須)
4. **本文** (必須・詳しく)
5. **送信**

送信後、担当者が確認次第ご返信します。

### 6-3. お問い合わせ確認・返信

ヘッダーの **お問い合わせ** で履歴一覧。

ステータス:
- **新規** — 管理者がまだ見ていない
- **対応中** — 担当者が確認中
- **顧客返信待ち** — 返信が来ている (要確認)
- **解決済み**
- **クローズ**

行クリックでスレッド表示。**返信を送信** から追加メッセージを送れます (クローズ後は不可)。

## 7. 通知履歴

ヘッダーの **通知** から。

過去に受信した通知メールが新しい順に並びます (20 件/ページ)。

- 件名・受信時刻・テンプレ種別
- **本文を表示** で展開
- 失敗した通知はエラー詳細表示

> 通知メールは Resend で配信されます。届かない場合は迷惑メールフォルダもご確認ください。

## 8. よくある操作

### 8-1. はじめての発注
1. **/order** で商品を探す
2. BOX か CT を選んで数量を入れて **カートに追加**
3. 右カート確認 → 免責同意 → **リクエスト送信**
4. メール届く → 担当者から確定連絡
5. **/mypage** で進捗を確認

### 8-2. 請求書 PDF をダウンロード
1. **/mypage** → 請求書一覧
2. 該当行をクリック
3. モーダル下部の **PDF をダウンロード**

### 8-3. 引っ越し / 担当変更
1. **/profile** へ
2. 住所・電話・担当者名を編集 → 保存
3. メールアドレス変更が必要な場合は管理者へ連絡

### 8-4. ランクが上がるまでどれくらい？
1. **/mypage** の「次ランクまで」と進捗バーで確認
2. 翌月 1 日に自動昇格

## 9. トラブルシュート

### 9-1. ログインできない
- **メアドかパスワード違い** → パスワード再設定 (`/forgot-password`)
- **ステータス suspended** → 管理者に連絡

### 9-2. 発注フォームに商品が出ない
- 管理者が公開設定をしていない可能性
- フィルタを全カテゴリ・全状態に戻して再度確認

### 9-3. 「BOX 単位の最低発注数は 12BOX です」
- 仕様。12 BOX 未満は発注不可
- CT 単位なら 1 CT (= 12 BOX 相当) から発注可

### 9-4. 「発注可能数を超えています」
- 在庫が足りない。残数を確認 (商品カードに「残 NN BOX」表示)
- 他ショップが先に確保した可能性あり

### 9-5. PDF が「PDF はまだ生成されていません」
- 管理者がまだ請求書 PDF を作成していない
- 担当者にご連絡ください

### 9-6. 通知メールが来ない
- 迷惑メールフォルダを確認
- `/notifications` の履歴で「sent」と表示されていれば送信は成功している
- `failed` の場合は担当者に連絡

### 9-7. その他
お問い合わせフォームから「アカウント」カテゴリで送信してください。
