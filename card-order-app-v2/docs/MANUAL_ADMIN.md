## 1. はじめに

このマニュアルは社内スタッフ (admin / super_admin) 向けです。

### URL
- 本番: <https://card-order-app-v2.vercel.app>
- ログイン: <https://card-order-app-v2.vercel.app/login>

### ロール
| ロール | できること |
|---|---|
| **shop** | 加盟ショップ。発注・自分の情報閲覧・問い合わせのみ |
| **admin** | 通常の管理者。発注承認・請求書発行・在庫管理・通知送信など |
| **super_admin** | admin + ランク閾値変更・スタッフ追加/権限変更・監査ログ閲覧 |

---

## 2. ログインとロール

### ログイン
1. `/login` でメアド + パスワード
2. ロールに応じて自動分岐:
   - admin / super_admin → `/admin`
   - shop → `/mypage`

### 自分のロール確認
左サイドバー最下部にメアドが表示されます。表示されている項目数でロールがわかります:
- 通常 admin: タスクまで
- super_admin: スタッフ・監査ログまで見える

## 4. 在庫管理 (商品マスタ)

`/admin/inventory`

### 4-1. 商品一覧

| 列 | 説明 |
|---|---|
| ☑ | チェックボックス (一括操作用) |
| シリーズ | ゲームタイトル (例: ポケモンカード, ヴァンガード) |
| 商品名 / 型番 | クリックで詳細編集ページへ |
| 定価 / 案内掛け | 案内掛け = 実掛け率 + 上乗せ率 |
| 在庫 | 残数 / 計画数 (BOX) — 残 0 は赤、残 20% 以下は琥珀 |
| 締切 | 期限超過は赤字 + ⚠ |
| フロー | 配分品 / カット割 |
| 状態 | 公開/非公開 + 受付中/受付停止/終了 |

### 4-2. 検索・絞り込み

- **検索ボックス**: シリーズ・商品名・型番・フル名
- **シリーズ別**: ドロップダウン
- **状態別**: 公開のみ / 非公開のみ / 受付中 / 受付停止 / 終了
- **ソート**: 新着 / 締切 / シリーズ名 / 商品名 / 在庫多い順 / 価格高い順

### 4-3. 一括公開/非公開

1. 商品行のチェックボックスで複数選択 (上部チェックで全選択)
2. 上部の青いバーから:
   - **公開する** / **非公開にする**
   - **受付中に** / **受付停止に** / **終了に**
3. 確認ダイアログ → OK

### 4-4. Excel 取込

右上 **Excel取込**:

1. ファイルを選択 → アップロード
2. 結果トースト + 詳細パネル表示
3. **新規追加** / **更新** (差分つき) / **スキップ** / **エラー** が確認できる

期待される Excel フォーマット (橋本さん「入荷案内リスト」形式):

| 列 | 内容 |
|---|---|
| A | 案内日付ラベル (任意) |
| B | シリーズ (商品タイトル) |
| D | 商品名 (フル) |
| E | 型番 |
| F | 発注可能数 (BOX) |
| G | 発注締切日 |
| H | 掛け率 (0.76 / "76%" 両対応) |
| I | 販売価格 ("6.000(税込み6.600）" 対応) |
| J | 配分 / カット |
| K | 備考 |

### 4-5. 新規登録

右上 **新規登録** → 商品名・シリーズ・カテゴリ・実掛け率・定価・在庫を入力。

### 4-6. 商品詳細・編集

商品名クリック → 詳細ページ:

- **基本情報**: シリーズ / 商品名 / フル商品名 / 型番 / カテゴリ
- **掛け率**: 実掛け率 + 上乗せ率 = 案内掛け率 (自動計算プレビュー)
- **価格・在庫**: 定価 / 発注可能数 / 1CT あたり BOX / 最低発注数
- **フロー**: 配分確定品 / カット割
- **公開設定**: 公開する / 承認済み / 受付状態
- **締切**: order_deadline
- **備考**: notes

右側に **商品画像** (アップロードで Sharp 自動リサイズ → WebP)。

## 5. 発注管理

`/admin/orders`

### 5-1. 一覧

全発注を新着順表示 (最大 100 件)。フローバッジ・ステータス・発送・金額が見える。

### 5-2. 詳細・承認

行の **詳細** をクリック → `/admin/orders/[id]`:

**左カラム**:
- 基本情報 (ショップ / 商品 / フロー / 希望数量 / 仮確定・確定数 / 価格 / 掛け率 / リベート率)
- 金額試算 (確定数量ベース)
- 操作履歴 (監査ログ)

**右カラム**:
- **ステータス更新**:
  - 次のステータスを選択 (`リクエスト` → `発注調整中` → `仮確定` → `確定` または `キャンセル`)
  - 仮確定 / 確定時は数量を指定
  - 管理メモも編集可
  - 楽観的ロック付き (他のスタッフが先に編集していれば 409 エラー → リロード)
- **発送ステータス**: 未出荷 → 準備中 → 出荷済 → 配送中 → 完了
- 追跡番号を登録

### 5-3. 2 フロー対応
- **配分品 (haibun)**: リクエスト → 仮確定 → 確定
- **カット割 (cut)**: リクエスト → 発注調整中 (数量配分) → 仮確定 → 確定

### 5-4. 通知発火

ステータス変更時に自動でショップへ通知メール:
- 仮確定 → `order_provisional`
- 確定 → `order_confirmed`
- 出荷済 / 配送中 → `order_shipped`

### 5-5. CSV エクスポート

右上 **CSV エクスポート** で発注全件を CSV ダウンロード (最大 5000 件)。

### 6-2. CSV インポート (移行用)

- **Excel** 形式: Google フォーム出力 (顧客マスター / 卸_ショップ登録フォーム) を自動検出
- 重複 (email 一致) は更新、新規は Auth ユーザーも自動作成

### 6-3. CSV 出力

右上 **CSV出力** で全顧客を CSV ダウンロード。

### 6-4. 新規ショップ登録

右上 **新規ショップ登録** → 詳細フォーム:

- 会社名・担当者・メアド (任意) ・電話・住所
- 初期ランク
- 「招待メールを送信する」「即時 active にする」チェック
- メアドなしでも登録可 (後から追加)

### 6-5. ショップ詳細

会社名クリック → `/admin/shops/[id]`:

**編集セクション**:
- 基本情報 (会社名 / 担当 / メール / 電話 / ステータス / 住所 / 納品先)
- 運営情報 (運営形態 / 開業日 / 累計発注額・手動入力)
- ランク・掛け率

**過去ランク変動履歴** (最大 24 件)

**請求書一覧 + 過去請求書 (legacy) 追加ボタン**

**販売店調査履歴**

**右サイド**:
- 基本情報サマリ
- 宣誓書アップロード (PDF・失効日含む)
- 開業届 / 履歴事項全部証明書アップロード

### 6-6. 招待メール再送

メアドあり・user_id 紐付け済みなら、右側に **招待メール再送** ボタンが出る。
パスワード再設定リンクを再送できる。

## 7. 請求・入金管理

`/admin/billing`

### 7-1. 一覧
全請求書を発行日降順 (最大 200 件)。発行時のリベート率 / 金額内訳 / ステータス。

### 7-2. 請求書発行ウィザード

右上 **請求書発行** → `/admin/billing/new`:

1. **ステップ 1**: ショップ選択 (active + pending)
2. **ステップ 2**: そのショップの「確定」発注のうち未請求のものを選択
   - 過去に請求済みのものは「請求済」バッジでチェック不可
3. **ステップ 3**: 内容確認 (自動計算: 小計 / リベート / 課税対象 / 消費税 / 合計) + 支払期限を入力
4. **請求書を発行**

発行時:
- INV-YYYYMM-NNNN 自動採番
- 発注の `subtotal` / `rebate_amount` / `total_price` を確定
- invoice_items を作成
- ショップへ `invoice_issued` 通知メール
- 詳細ページへ移動

### 7-3. 請求書詳細 + 入金消込

`/admin/billing/[id]`:

- 請求情報 / 明細 / 金額内訳
- 右側に **入金記録** フォーム
  - 入金額 + 入金日 → **入金を記録**
  - 全額入金で `入金済み`、部分入金で `一部入金` に自動遷移
- **PDF を生成 / 再生成** ボタン (Sharp PDF → Storage アップロード → URL 更新)
- 入金済みの場合は **領収書を発行** ボタン (領収書 PDF 生成)

### 7-4. 過去請求書取込

ショップ詳細ページの「+ 過去の請求書を追加」から、本システム外で発行した PDF を取込可能 (legacy フラグ付き)。

### 7-5. CSV 出力

右上 **CSV出力** で全請求書 CSV ダウンロード。

## 8. リベート・ランク管理

`/admin/rebate` (super_admin のみ)

### 8-1. 予約済み変更バナー

月途中で変更を保存すると、**翌月 1 日に自動適用される予約**として登録されます。バナーで一覧表示。

### 8-2. ランク閾値・リベート率 (現在の有効値)

| ランク | 昇格基準 (円) | リベート率 (0〜1) |
|---|---|---|
| プラチナ | 1,000,000 | 0.10 |
| ゴールド | 500,000 | 0.07 |
| シルバー | 200,000 | 0.05 |
| ブロンズ | 100,000 | 0.03 |
| スタンダード | 0 | 0.00 |

編集して **保存** → 予約登録 → 翌月初に Cron が反映。

### 8-3. 月次ランク更新の手動実行

右上のボタンで `/api/cron/rank-update` を手動実行可能。

### 8-4. 変更ログ

過去 30 件の閾値・リベート率変更履歴:
- 作成日時 / ランク / 変更内容 / 適用予定日 / 状態 (予約中 / 適用済 / 失敗 / キャンセル)
- 失敗時はエラー詳細表示

### 8-5. ショップランク変動

過去 30 件のショップ別ランク変動を表示 (どの月に誰が何ランクから何ランクへ動いたか)。

- **解決済み** — 解決。`resolved_at` 記録
- **クローズ** — 完全終了 (返信不可)

## 17. 典型ワークフロー

### 17-1. 新規ショップの立ち上げ
1. `/admin/shops/new` で会社情報入力 (メアドあり + 招待メール ON + 即時 active OFF)
2. ショップにメール届く → パスワード設定
3. **/admin/shops/[id]** で宣誓書 / 開業届の提出待ち
4. 提出後、状態を **active** に変更
5. 発注フォームから注文してもらう

### 17-2. 発注 → 請求 → 入金フロー (配分品)
1. ショップが `/order` から発注 → ステータス **リクエスト**
2. `/admin/orders` で詳細 → **仮確定** に変更 (数量指定)
3. 確認後 **確定** に変更 → 通知メール
4. 在庫 `ordered_qty` 自動加算
5. **発送ステータス → 出荷済 + 追跡番号**
6. `/admin/billing/new` でこのショップの確定発注を選択 → 請求書発行 → 通知メール
7. 入金確認後 `/admin/billing/[id]` で消込
8. 入金済みになったら **領収書を発行**

### 17-3. 発注 → 請求 → 入金フロー (カット割)
1. ショップ発注 → **リクエスト**
2. `/admin/orders/[id]` → **発注調整中** (配分数量を入力)
3. **仮確定** に変更 → 通知 (ショップに「カット結果」を共有)
4. ショップ了承後 → **確定**
5. 以降は配分品と同じ

### 17-4. 月次ランク反映と通知
1. 毎月 1 日 0:00 (UTC) に Cron `/api/cron/rank-update` 実行
2. 各ショップの先月発注額を計算
3. 昇降格判定 → 反映 → ショップに `rank_changed` 通知

### 17-5. リベート設定変更 (月途中)
1. `/admin/rebate` で閾値・率を編集 → 保存
2. **予約として登録** (即時反映されない)
3. 翌月 1 日 0:01 (UTC) に Cron `/api/cron/apply-rank-settings` が反映
4. 変更ログで適用結果確認

### 17-6. Excel で大量在庫更新
1. 仕入元から Excel 受領
2. `/admin/inventory/import` でアップロード
3. 結果サマリ確認 (新規 / 更新 / スキップ / エラー)
4. 重複は差分表示で確認 → 必要なら個別編集

## 18. トラブルシュート

### 18-1. ログインできないスタッフがいる
1. `/admin/staff` で該当ユーザーの **active** 状態確認
2. **active** にチェック → 保存
3. **招待メール再送** で改めて送信

### 18-2. 発注の在庫数がずれている
- `products.ordered_qty` は確定時に自動加算、キャンセル時に減算
- もしずれたら商品詳細から手動調整 → 監査ログに記録される

### 18-3. 請求書 PDF が表示されない
- 詳細ページで **PDF を生成 / 再生成** ボタンクリック
- 失敗時は監査ログでエラー確認

### 18-4. 通知メールが届かない
- `RESEND_API_KEY` 未設定なら送信スキップ (`/admin/notifications` ログを確認)
- ステータス `failed` の場合は `error_detail` で原因確認
- ショップが `suspended` だと自動で送信スキップ

### 18-5. リベート変更が反映されない
- 月途中の変更は**翌月 1 日まで適用されない仕様**
- 急ぎなら DB 直接更新 (super_admin で Supabase Studio から) + 監査ログにメモを残す

### 18-6. ステータス更新で 409 エラー
- 他のスタッフが先に編集している
- ブラウザを再読込して最新の状態で再操作

### 18-7. Excel 取込で大量エラー
- フォーマットが想定外の可能性
- フォーマット仕様は `/admin/inventory/import` ページ上部に記載
- 個別エラー詳細を確認して問題行を Excel で修正 → 再アップ

### 18-8. 月次バッチが失敗した
- `batch_logs` テーブルで詳細確認 (Supabase Studio で SQL)
- `/admin/rebate` で「月次ランク更新を手動実行」ボタンから再実行可能

## 補足

- 全画面とも Cmd+R (Mac) / F5 (Win) で再読込
- 全画面とも責任分界:
  - ショップ自身が更新できる: 自分のプロフィール、パスワード、宣誓書アップ
  - 管理者のみ: ステータス変更、請求書発行、ランク手動上書き、メアド変更、スタッフ追加

質問があれば super_admin に連絡してください。
