## 1. ロールと権限

| ロール | 対象 | できること |
|---|---|---|
| `super_admin` | 社内責任者 | 全機能 + リベート設定変更 + スタッフ管理 + 監査ログ |
| `admin` | 社内スタッフ | 在庫・発注・顧客・請求・通知・タスクなど日常業務すべて |
| `shop` | 加盟ショップ | 発注・マイページ・プロフィール (ショップ画面のみ) |

ロールは Supabase Auth の `user_metadata.role` で管理。スタッフ管理画面 (super_admin) から変更できます。

## 3. 在庫管理 `/admin/inventory`

### 一覧
- **検索**: シリーズ・商品名・型番
- **絞り込み**: シリーズ別 / 公開状態 / 受付状態
- **ソート**: 新着 / 締切 / シリーズ名 / 商品名 / 在庫多い順 / 価格高い順
- **一括操作**: チェックボックス選択 → 公開 / 非公開 / 受付中 / 受付停止 / 終了 をまとめて変更
- 在庫の色分け: 残 0 = 赤 / 残 20% 以下 = 琥珀

### Excel 取込 (`Excel取込` ボタン)
橋本さん「入荷案内リスト」形式に対応:

| 列 | 内容 |
|---|---|
| B | シリーズ (ゲームタイトル) |
| D | 商品名 |
| E | 型番 |
| F | 発注可能数 (BOX) |
| G | 発注締切日 |
| H | 掛け率 (0.74 or 74%) |
| I | 販売価格 — `6.000(税込み6.600)` 形式対応 |
| J | 配分 / カット |
| K | 備考 |

- 重複 (シリーズ + 商品名 + 型番) は**自動上書き** — 差分内容が結果画面に表示されます
- 取込結果: 新規 / 更新 / スキップ / エラーをポップアップ + 詳細リストで確認

### 商品の編集
商品名クリック → 詳細ページ。全フィールド編集・画像アップロード (自動 800px WebP 化)・論理削除。

> 公開 (is_visible) + 受付中 + 締切内 + 在庫ありの商品だけがショップに表示されます。

## 4. 発注管理 `/admin/orders`

### 発注リクエストへの対応 (2 フロー)

```
【配分確定品 (haibun)】 リクエスト → 仮確定 → 確定
【カット割 (cut)】     リクエスト → 発注調整中 (数量配分) → 仮確定 → 確定
```

1. 一覧から該当発注の「詳細」をクリック
2. 右側のステータス更新パネルで次のステータスと数量を入力
3. **確定にすると在庫 (発注済数) が自動加算**、キャンセルで自動復元
4. 各ステータス変更でショップへ自動メール通知

### 発送管理
詳細ページの発送パネルで: 未出荷 → 準備中 → 出荷済 → 配送中 → 完了。追跡番号を入れて更新すると発送通知メールが飛びます。

### 手動登録 (システム外受注) `/admin/orders/new`
メール・電話で受けた発注を代理登録:
- **受注日を過去日付で指定可** → 月次集計・ランク計算に正しく反映
- ステータス「確定」で登録すると在庫を自動引き当て
- 出荷ステータス・追跡番号もその場で設定可
- 登録後はショップのマイページに表示され、通常の出荷・請求フローに乗ります

> 商品がマスタにない場合は先に在庫管理で登録してください。

### 発注リクエスト通知
新しいリクエストが届くと、環境変数 `ORDER_NOTIFY_EMAILS` に設定した宛先 (社内 + 問屋担当) へ「クライアント名・発注タイトル・希望数」が自動メールされます。

## 5. 顧客管理 `/admin/shops`

### ショップ詳細でできること
- 基本情報編集 (会社名・住所・メール・ステータス・ランク・個別掛け率)
- **運営情報**: 運営形態 / 開業日 (運営年数を自動表示・2 年未満は警告) / 累計発注額 (手動入力可)
- **宣誓書**: PDF アップ・失効日設定・ダウンロード
- **開業届 / 履歴事項全部証明書**: PDF アップ・署名付き URL で閲覧
- **過去請求書 (legacy)**: システム外で発行した請求書を PDF + 金額で取込 (一覧に「過去」バッジ)
- ランク変動履歴 / 直近請求書 / 調査履歴

### メールアドレスと招待
- メアド未設定のショップに後からメアドを追加 → 保存すると**ログインユーザーが自動作成**
- 「招待メール再送」でパスワード設定リンクを再送

### CSV 取込
Google フォーム出力 (事業進捗管理表) の「顧客マスター」シートを自動検出して一括取込。email 重複は既存を更新。

## 6. 新規ショップの受け入れフロー

```
1. メール一次問い合わせ → 簡易ヒアリング (自動返信メール・システム外)
2. 条件確認: 実店舗あり / 運営歴 (EC のみは不可)
3. /admin/shops → 「招待リンク発行」 で登録 URL を作成 (7/14/30 日期限)
4. URL をメールで案内
5. ショップが登録フォーム入力 + 規約同意 + メール認証 + パスワード設定
6. status=pending で登録される → 内容確認後、詳細画面で active に変更
```

- 招待リンクは 1 回使い切り。「URL コピー」「失効」操作が可能
- 使用済みリンクは「✓ 登録済」表示
- 登録フォームで EC のみを選んだ事業者は登録できない仕様

## 7. 変更申請の承認 `/admin/change-requests`

ショップからの**配送先住所の変更申請**を処理します (なりすまし対策のため申請制)。

1. サイドバー「変更申請」を開く
2. 現在値と変更後を見比べる
3. **✓ 承認して反映** → shops の配送先が書き換わり、承認メールが自動送信
4. **却下** → 理由を入力 (必須) → 理由付きの却下メールが送信

> 会社名・登録住所の変更はショップ側からはできません。本人確認のうえ、ショップ詳細画面から直接変更してください。

## 8. 請求・入金管理 `/admin/billing`

### ダッシュボード
- サマリ: 売掛残高 (未回収) / **期限超過** (赤) / 今月の入金 / 発行数
- ステータスタブ: 未入金 / 一部入金 / 入金済み / ⚠期限超過
- 期限超過行は赤背景 + 残額表示

### 請求書発行 (`請求書発行` ボタン)
1. ショップ選択 (active / pending 両方可)
2. 確定済み発注から請求対象を選択 (請求済みはグレー表示)
3. リベート・税の自動計算をプレビュー確認
4. 支払期限を設定 → 発行
5. 発行時にショップへ通知メール + 請求書番号自動採番 (INV-YYYYMM-NNNN)

### 計算ルール (重要)

**用語**
- **案内掛け率** = 実掛け率 + 上乗せ率 (ショップに個別掛け率 `rate_override` が設定されていればそれを優先)
- **リベート率** = ショップの現在ランクに対応する率 (プラチナ10% / ゴールド7% / シルバー5% / ブロンズ3% / スタンダード0%)

**通常請求 / 差額請求の金額**
```
小計(税抜)    = 定価 × 確定BOX数 × 案内掛け率        … 端数切り捨て
リベート額     = 小計 × リベート率                   … 端数切り捨て
手数料(税抜)  = 小計 × 2%                            … 四捨五入 (決済手数料)
課税対象額     = 小計 − リベート額 + 手数料
消費税         = 課税対象額 × 10%                     … 端数切り捨て
請求合計(税込) = 課税対象額 + 消費税
```
> 手数料は税抜2%。消費税を乗せると実質「商品代金の税込2.2%」相当になります。表示は外税 (小計・手数料・消費税を分けて表示)。

**カット品の保証金 (前受金)**
```
保証金額 = 定価 × 希望BOX数 × 案内掛け率 × 50%        … 前受金・消費税なし・端数切り捨て
```

**カット品の最終精算 (差額 / 返金)**
```
確定金額(税込) = 上記「請求合計」を確定BOX数で計算 (手数料込)
今回ご請求額   = 確定金額(税込) − お預かり保証金
  ├ プラス → 差額請求書 (final)
  └ マイナス → その絶対額を返金 (refund・支払通知書)
```

**計算例 (定価¥2,970 / 掛け率88% / スタンダード / 50BOX発注→確定40BOX)**
```
案内単価     = 2,970 × 0.88 = ¥2,613 (税抜)
保証金       = 2,613 × 50BOX × 50% = ¥65,325 (前受金)
確定小計     = 2,613 × 40BOX = ¥104,520
手数料       = 104,520 × 2% = ¥2,090
課税対象     = 104,520 − 0(リベート) + 2,090 = ¥106,610
消費税       = 106,610 × 10% = ¥10,661
確定金額税込 = ¥117,271
今回ご請求額 = 117,271 − 65,325(保証金) = ¥51,946 (差額請求)
```

### 入金消込・領収書
詳細ページで入金額・入金日を記録 (一部入金対応)。ステータスは自動遷移。入金済みになると**領収書 PDF** を発行できます。

### カット品の請求 — 保証金 → 最終精算 (差額 / 返金)

メーカー提供数量が変動する**カット品**は「先に保証金50%を請求 → 数量確定後に差額 (または返金) を請求」の2段階で処理します。

```
① 保証金を請求 → ② 入金を記録 → ③ 数量を確定 → ④ 最終精算 → ⑤ PDF発行
```

**① 保証金請求書 (50%) を発行**
発注管理 → 対象のカット発注の「詳細」→ 右上 **「保証金請求書(50%)を発行」**。希望数量 × 50% の保証金請求書 (件名「保証金分」・税なし) が作られます。
※ ショップ側発注のカット品は自動発行。手入力運用のときだけこのボタンを使います。

**② 保証金の入金を記録**
請求 →「保証金」バッジの請求書 → 右側「入金記録」に金額・入金日 →「入金を記録」。

**③ 数量を確定**
発注詳細でステータスを「確定」にし、**確定数 (例: 40BOX)** を入力して保存。
※ 締切 (発注期限の7日前) を過ぎても未確定の発注は、発注一覧に「要確定」表示 + 上部バナーが出ます。

**④ 最終精算 (差額 or 返金)**
「保証金」請求書の詳細 → 右上 **「最終精算する」**。**確定金額 (満額・手数料込) − お預かり保証金** を計算し、
- プラス → **「精算」バッジの差額請求書** (前受金充当後の「今回ご請求額」)
- マイナス → **「返金」バッジ**で**支払通知書 (返金案内)** を自動生成
※ 精算済みの場合は「既に精算済みです」と出て二重発行はされません。

**⑤ PDF発行**
差額は「PDFを開く」、返金は「支払通知書を開く」。リンクは開くたび再発行され**失効しません**。

**金額の考え方 (例: 50BOX発注 → 確定40BOX)**

| 段階 | 数量 | 内容 |
|---|---|---|
| ① 発注 | 50 BOX | 希望数量 |
| ② 保証金50% | 25 BOX相当 | 先に請求・入金 |
| ③ 確定 | 40 BOX | 配分確定数 |
| ④ 差額請求 | 15 BOX相当 | 満額40 − 保証金25 |

**手数料**: 全請求書に決済手数料 (商品代金税抜 × **2%** → 消費税を乗せて実質税込2.2%) が計上されます (外税表示)。

**請求書バッジ早見表**

| バッジ | 種別 | 内容 |
|---|---|---|
| 保証金 | deposit | 前受金50%・件名「保証金分」 |
| 精算 | final | 差額請求・前受金充当後の「今回ご請求額」 |
| 返金 | refund | 保証金超過分・支払通知書で返金案内 |

> 発行元・振込先 (株式会社パレットグループ / GMOあおぞらネット銀行 カ)パレットグループ) はPDFに自動で記載されます。

## 9. リベート・ランク管理 `/admin/rebate` (super_admin)

### 重要: 変更は翌月から反映
ランク閾値・リベート率を変更しても**即時には反映されません**。翌月 1 日に自動適用される「予約」として登録されます (当月の集計・請求額が壊れるのを防ぐため)。

- 予約中の変更は黄色いバナーに表示
- **変更ログ**で「いつ・誰が・何を変更し、適用が成功 / 失敗したか」を確認可能 (失敗時はエラー内容も表示)

### 月次ランク更新
毎月 1 日 0:00 (UTC) に自動実行。手動実行ボタンもあり (冪等なので複数回押しても安全)。

### ランク基準 (デフォルト)

| ランク | 昇格基準 (月次) | リベート率 | 維持条件 |
|---|---|---|---|
| プラチナ | ¥1,000,000 | 10% | 基準の 50% 以上 |
| ゴールド | ¥500,000 | 7% | 同上 |
| シルバー | ¥200,000 | 5% | 同上 |
| ブロンズ | ¥100,000 | 3% | 同上 |
| スタンダード | — | 0% | — |

## 18. トラブルシュート

| 症状 | 対処 |
|---|---|
| ショップから「メールが届かない」 | Resend ダッシュボード → Logs で送信記録を確認。迷惑メール → 「迷惑メールではない」を案内 |
| 「リンクが無効」と言われた | リンクは 1 回のみ有効。/forgot-password から再送を案内 |
| 発注確定でエラー「データが更新されています」 | 他のスタッフが同時編集。再読み込みして再操作 |
| 請求書発行で対象発注が出ない | 発注が「確定」になっているか・請求済みでないかを確認 |
| ランク設定を変えたのに反映されない | 仕様 (翌月 1 日適用)。リベート管理の予約バナーを確認 |
| バッチが動いたか不安 | リベート管理の変更ログ / batch_logs で実行結果を確認 |
| 在庫数が合わない | 発注詳細の操作履歴と監査ログで増減の経緯を追跡 |
