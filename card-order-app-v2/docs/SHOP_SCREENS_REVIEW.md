# ショップ側画面レビュー

実装済み画面 3 種 (login, order, mypage) の現状と改善候補。

---

## 1. ログイン `/login`

### 実装済み
- メアド + パスワード入力
- 大きめサイズで PC でも見やすい
- ログイン後 admin / shop でリダイレクト分岐
- ブラウザ HTML5 バリデーション

### 改善候補
| 優先 | 内容 |
|---|---|
| 高 | **「パスワードを忘れた方」リンク** → Supabase の reset-password 画面へ |
| 中 | エラーメッセージの日本語化精度 (現状「メールアドレスまたはパスワードが正しくありません」固定) |
| 低 | ロゴ画像差し替え (現状テキストのみ) |

---

## 2. 発注フォーム `/order`

### 実装済み
- 公開中 (`is_visible=true` && `status='受付中'`) の商品一覧
- BOX / CT 単位切替
- 数量バリデーション (最低 12 BOX 等)
- 残在庫表示
- カート (画面右ペイン・PC は sticky)
- 免責事項チェックボックス
- 確認モーダル
- リクエスト送信
- 商品ごとの案内掛け率表示 (ショップランク基準)

### 改善候補
| 優先 | 内容 |
|---|---|
| **高** | **商品画像表示** — 現状は文字情報のみ。カードゲームは見た目大事 |
| **高** | **カテゴリフィルタ** — ポケモン/ワンピース/その他 タブ |
| **高** | **検索ボックス** — 商品名・型番で部分一致 |
| 中 | **締切日表示 + 残り日数アラート** — 「あと 3 日」みたいなバッジ |
| 中 | **ソート機能** — 締切順 / 価格順 / 新着順 |
| 中 | **カート永続化** — ページ遷移しても保持 (localStorage) |
| 低 | **商品詳細モーダル** — 説明・備考の長文を読みやすく |

---

## 3. マイページ `/mypage`

### 実装済み
- 現ランク + リベート率
- 今月の発注額
- 次ランクまでの不足額
- 直近 10 件の発注 (商品 / 数量 / ステータス / 発送)
- 直近 10 件の請求書 (発行日 / 合計 / ステータス / PDF DL)

### 改善候補
| 優先 | 内容 |
|---|---|
| **高** | **発注詳細ポップアップ** — クリックで詳細 (確定数量・金額・履歴) |
| **高** | **請求書詳細 / PDF プレビュー** — 直接 DL じゃなくページで内訳確認 |
| **高** | **発注ステータスのバッジ色分け** — 確定=緑 / 仮確定=黄 / リクエスト=灰 |
| 中 | **絞り込み** — ステータス・期間でフィルタ |
| 中 | **「もっと見る」/ ページネーション** — 履歴 10 件超への対応 |
| 中 | **ランク進捗バー** — 円グラフ or 進捗バーで視覚化 |
| 低 | **CSV エクスポート** — 自分のショップの発注履歴を DL |

---

## 4. ショップ側にない画面

| 必要度 | 候補 |
|---|---|
| **高** | **ショッププロフィール編集** `/profile` — 担当者・電話・住所変更 |
| 中 | **パスワード変更** `/profile/password` |
| 中 | **宣誓書アップロード** (ショップ側からも提出できるように) |
| 中 | **個別発注ステータス確認** `/orders/[id]` — マイページから飛ぶ詳細 |
| 低 | **お知らせ / 通知履歴** `/notifications` — 通知メールの履歴閲覧 |
| 低 | **販売店調査の閲覧** (admin が登録した調査メモのうち、共有してよいもの) |

---

## 推奨アクションプラン

### Phase A: 発注フォームの体験向上 (1〜2 セッション)
- 商品画像表示
- カテゴリフィルタ
- 検索
- 締切バッジ

### Phase B: マイページの拡充 (1 セッション)
- 発注詳細ポップアップ
- ステータス色分け
- ページネーション

### Phase C: プロフィール周り (1 セッション)
- `/profile` 編集画面
- パスワード変更
- 宣誓書ショップ側アップロード

### Phase D: 残り (1 セッション)
- 通知履歴
- お忘れメール / reset 画面の整備
- マイページ CSV エクスポート

## 現状の見た目

[docs/mockup.html](mockup.html) の 「1. ログイン」「2. 発注フォーム」「3. マイページ」セクションを参照。
ローカルで `npm run dev` 中なら以下 URL で実物確認可能 (ショップアカウントでログインが必要):

| URL | 説明 |
|---|---|
| http://localhost:3000/login | ログイン |
| http://localhost:3000/order | 発注フォーム |
| http://localhost:3000/mypage | マイページ |

> 自分の super_admin アカウントでは shop 画面にリダイレクトされないため、
> 確認用の shop ユーザーが必要。`/admin/shops/new` で別メアド + invite で作るか、
> 既存ショップに email を追加して invite するのが手早い。
