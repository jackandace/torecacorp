# 【河津さん向け】卸の新規申込みフローの変更と審査作業のご案内

(2026-09-16 リリース)

## 何が変わったか(3行で)

- 卸の問い合わせ対応が **Google フォーム → アプリ内の審査申込みフォーム** に変わりました
- 申込みは **管理画面「ショップ審査」** に自動で並び、**承認ボタンを押すだけで招待メールまで自動送付** されます
- 関連メールの担当・返信先はすべて **河津さん (m.kawazu@torecacorp.jp)** になっています

---

## 新しい流れ(全体像)

```
① Studio 問い合わせ (卸取引について)
      ↓ 自動返信 (河津名義・審査フォームの案内) ※河津さんにも通知メール
② 事業者が申込みフォームに入力
   https://card-order-app-v2.vercel.app/apply
      ↓ 申請者に受付確認メール / 河津さんに「新規申込み」通知メール
③ 管理画面「ショップ審査」で内容を確認
      ↓
④-A 承認 → 登録リンク付きの審査通過メールが自動送信 (リンクは14日有効)
④-B 却下 → 審査メモを記録 (お断りメールは任意)
      ↓ (承認の場合)
⑤ 事業者が登録リンクからアカウント登録
   ※申込み内容が入力欄に自動反映されるので、先方の手間はほぼなし
      ↓
⑥ 以降は従来どおりの新規ショップの流れ
```

## 審査作業の手順(ステップバイステップ)

### 1. 申込みに気づく

新しい申込みが入ると「**【ショップ審査】新規申込み: ○○様**」というメールが届きます。
メール内のリンク、または管理画面サイドバーの「**ショップ審査**」から一覧を開いてください。
審査待ちが残っていると、タブに赤い件数バッジが表示されます。

### 2. 内容を確認する

一覧のカードに申請内容がすべて表示されます。主な確認ポイント:

| 確認項目 | 見るところ |
|---|---|
| 実店舗があるか | 運営形態 (実店舗のみ / 実店舗+EC)・登録住所 ※ECのみはフォーム側で申込み不可 |
| 運営歴 | 開業日 (ティア1タイトルは運営1〜2年以上が目安) |
| 実在性 | 店舗紹介 / EC サイト URL (SNS 可) |
| 請求・配送まわり | 請求書発行先名称・配送先住所・受取人名 |

### 3-A. 承認する場合

1. カード右側の「**承認して招待メールを送る**」を押す
2. 確認ダイアログで OK
3. これだけで完了です。申請者に **登録リンク付きの審査通過メールが自動送信** されます (リンク有効期限14日)
   - もしメール送信に失敗した場合は、画面に登録リンクが表示されるので、それをコピーして手動でメール案内してください
   - 期限切れになった場合は、従来どおり「顧客管理 → 招待リンク」から再発行できます

### 3-B. 却下する場合

1. 「**却下…**」を押す
2. 審査メモ(却下理由・社内用。申請者には見えません)を入力
3. **申請者にお断りメールを送る場合のみ**チェックを入れる(デフォルトは送信しない=記録のみ)
4. 「却下を確定」

### 4. 履歴の確認

「承認済み」「却下」タブでいつでも過去の審査結果・メモを確認できます。

## メールまわりの補足

- アプリからの自動メール(受付確認・審査通過・お断り)の送信元は `noreply@torecacorp.jp` ですが、**返信はすべて河津さんに届く設定**にしてあります
- Studio 問い合わせへの自動返信も、名義・返信先とも河津さんになっています(送信元アカウントの都合で鈴木の Gmail 発ですが、返信は河津さんに届きます)
- 申込み内容で不明点があれば、一覧に表示されているメールアドレスに直接連絡して確認してから審査すれば OK です(承認・却下はいつ押しても大丈夫です)
