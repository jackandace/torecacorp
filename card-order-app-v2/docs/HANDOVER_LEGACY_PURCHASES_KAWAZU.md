# 【河津さん向け】購入履歴（アプリ運用以前）機能のリリースとテストのお願い

お疲れさまです！ご要望いただいていた「卸アプリ運用以前の購入履歴」を実装しました。
変更点とテスト方法をまとめたので、お手すきのときに確認をお願いします🙇‍♀️

---

## 変更点まとめ

### 1. 購入履歴（アプリ運用以前）を登録できるようになりました
- 場所: 管理画面 → 顧客管理 → お客様を開く → 上部の「購入履歴（卸アプリ運用以前）」
- 登録できる項目: 購入日・商品名・数量・単位・単価・金額・出荷状況（出荷済／未出荷）・備考・社内メモ
- 金額はすべて**税抜**。「数量×単価」で自動計算され、値引きなどは金額欄を直接直せます
- **備考はお客様にも見えます**。社内だけのメモは「社内メモ」欄へ（お客様には表示されません）
- 未出荷の行は黄色で表示され、出荷したら「編集」で「出荷済」に切り替えます（お客様への通知メールは送りません）
- ランク・リベート・請求・累計取引額の計算には**一切入りません**（参照用の記録です）

### 2. テンプレートExcelでまとめて取り込めます
- 同じページの「テンプレートをダウンロード」→「購入履歴」シートの2行目から入力 →「一括取込」
- 取り込む前に「内容を確認」で全行をチェックします。**エラーが1行でもあると登録できない**ので、崩れたデータが入る心配はありません
- テンプレートの見出しを変えたり列を足したりしたファイルは受け付けません
- 間違えて取り込んだときは、ページ下の「取込履歴」→「この取込を取り消す」でまとめて元に戻せます

### 3. 当時の請求書（PDF）を紐付けられます
- 同じページの「過去請求書（PDF）」欄 →「+ 過去の請求書を追加」でPDFをアップロード
- 一覧で請求書に含まれる行にチェック → 上に出るバーで請求書を選んで「請求書に紐付け」（1枚に何行でもOK）
- 請求書ごとに「紐付け件数・合計（税抜）」と「請求書の金額（税込）」が並ぶので、漏れや付け間違いを見比べられます
- **別のお客様の請求書は紐付けできない**ようにシステム側で止めています

### 4. お客様のマイページに表示されます
- 登録が1件以上あるお客様には、マイページに「購入履歴（アプリ運用以前）」が出ます（閲覧のみ・期間／商品名で検索可）
- 請求書を紐付けた行には「📄 請求書」リンクが付き、当時のPDFを開けます

### 5. 既存機能の不具合修正（過去請求書のPDF）
- これまで顧客詳細からアップした「過去請求書」は、「PDFを開く」を押すと**アップしたPDFではなく、システムが作り直した別のPDF**が表示されていました（お客様側・管理側とも）
- **アップしたPDFがそのまま開く**ように直しました。過去にアップした請求書も元のPDFが開けるよう復旧しています

### 操作マニュアル（録画つき）
管理画面 → 操作マニュアル → 一番上の「🎬 購入履歴（卸アプリ運用以前）の登録」
1件登録・一括取込・出荷済への切り替え・取込の取り消しを、実際の操作の録画で見られます。

## テスト方法（15分くらい）

テスト用のお客様「**鈴木テスト商店**」にデモデータを入れてあるので、そこで試してください。
（顧客管理の検索で「鈴木テスト」→「鈴木テスト商店」→ 上部の「購入履歴（卸アプリ運用以前）」）

| # | やること | 確認ポイント |
|---|---|---|
| 1 | 「+ 購入履歴を追加」で1件登録 | 金額が数量×単価で自動で入る／保存後に一覧と上の合計が増える |
| 2 | 登録した行を「編集」→ 出荷状況を「未出荷」に | 行が黄色になり、上の「未出荷」件数が増える |
| 3 | 「テンプレートをダウンロード」→ 2〜3行入力（1行はわざと購入日を「12月5日」にする）→「一括取込」→「内容を確認」 | エラーの行が赤く表示され、登録ボタンが押せない |
| 4 | Excelの日付を「2025/12/05」に直して再度「内容を確認」→「この内容で登録」 | 登録され、「取込履歴」に今回の取込が出る |
| 5 | 「取込履歴」→「この取込を取り消す」 | 取り込んだ行だけが消え、手入力の行は残る |
| 6 | 「過去請求書（PDF）」欄の「KAKO-TEST-001」の「開く」 | テスト用PDF（「TEST INVOICE KAKO-TEST-001」と書かれたもの）が開く |
| 7 | 行にチェック →「請求書に紐付け」／「紐付けを解除」 | 行の「📄 請求書」表示が付いたり外れたりする |
| 8 | （お客様側）鈴木テスト商店のアカウントでマイページを開く | 「購入履歴（アプリ運用以前）」が表示され、社内メモが見えない／紐付けた行から請求書PDFが開ける |

※ 8番はお客様アカウントでのログインが必要なので、鈴木さんにお願いしてください。
※ テストで入れたデータは、鈴木テスト商店のものなら消しても残しても問題ありません。

## 本番のお客様で使い始めるときの注意

- 実際のお客様（パチパチトレカさん等）に登録すると、**すぐにそのお客様のマイページに表示されます**。内容を確認してから登録してください
- 備考欄はお客様に見えます。社内向けのことは必ず「社内メモ」へ
- 請求書を紐付けたら、請求書ごとの「紐付け件数・合計」と請求書の金額を一度見比べてください

不明点や「ここが使いにくい」があれば気軽に教えてください！
