## 1. はじめに

このシステムは PALETTE GROUP トレカ商事カンパニーから商品を**卸価格で発注**するための専用システムです。

### 推奨環境
- **PC**: Chrome / Safari / Firefox の最新版
- **スマートフォン**: iOS Safari / Chrome

### ご利用条件
- 実店舗を運営するトレーディングカード取扱事業者様 (**EC のみの事業者様とはお取引できません**)
- 利用注意事項・免責事項への同意が必要です (登録時に表示)

## 2. アカウント登録

### 2-1. 新規お取引をご希望の方

1. まずは**メールでお問い合わせ**ください
2. 簡易ヒアリング (運営形態・実店舗の運営歴など) にご回答ください
3. 審査通過後、**登録案内リンク**をメールでお送りします
4. リンク先の登録フォームで事業者情報を入力
   - 会社名・屋号 / 担当者 / メール / 電話 / 住所
   - 運営形態 (実店舗のみ / 実店舗 + EC など) と開業日
5. **利用注意事項・免責事項**を確認のうえ同意にチェック → 登録
6. 認証メールが届くので、リンクからパスワードを設定
7. ログイン可能に (取引開始は弊社の最終確認後)

> ⚠ 登録リンクは **24 時間有効・1 回のみ**使用できます。期限切れの場合は担当者まで再発行をご依頼ください。

### 2-2. すでにメール・フォームでお取引中の方

1. ログイン画面の「**すでにショップ登録済みの方**」をクリック
2. ご登録のメールアドレスを入力
3. パスワード設定用のリンクがメールで届きます
4. パスワードを設定すればログインできます

> 💡 メールが迷惑メールフォルダに入っていた場合は、**先に「迷惑メールではない」を押してから**リンクをクリックしてください (リンクが無効になるのを防げます)。

## 3. ログイン・パスワード

- ログイン URL: `/login` (メール + パスワード)
- **パスワードを忘れた**: ログイン画面下部の「パスワードを忘れた方」→ メールで再設定リンク
- **パスワード変更**: ログイン後、プロフィール → パスワード変更 (8 文字以上)

## 4. 発注する

ヘッダーの **発注** から。

### 4-1. 商品を探す

- **検索ボックス**: シリーズ名・商品名・型番で部分一致
- **カテゴリタブ**: すべて / ポケモン / ワンピース / その他
- **ソート**: 発注締切が近い順 / 掲載が新しい順 / 定価が安い順 / 定価が高い順

> 発注締切を過ぎた商品は自動的に表示されなくなります。

### 4-2. 商品カードの見方

| 表示 | 意味 |
|---|---|
| 配分品 / カット割 | 発注フロー種別 (カット割は数量調整の可能性あり) |
| あと N 日 (黄/琥珀) | 締切まで 7 日以内 / 3 日以内 |
| 本日締切 (赤) | 当日中に発注が必要 |
| **SOLD OUT** | 在庫切れ (発注不可・グレー表示) |
| 残 N BOX | 現在の発注可能数 (**リアルタイム更新**) |
| 案内掛け率 | あなたのショップに適用される掛け率 |

### 4-3. カートに追加 → 送信

1. **BOX** (最低 12 BOX) または **CT** (最低 1 CT = 12 BOX) を選択
2. 数量を入力 → **カートに追加**
3. カートで内容と小計を確認
4. **免責事項に同意** にチェック → **リクエスト送信**
5. 確認モーダルで最終チェック → **送信する**
6. **✓ 完了モーダル**が表示されます → 「発注履歴を確認する」でマイページへ

> ⚠ **送信後のキャンセルはできません**。
> 💡 カートに入れた後に他店の発注で在庫が減った場合は警告が表示され、数量を調整するまで送信できません。

### 4-4. 発注後の流れ

```
リクエスト → (発注調整中) → 仮確定 → 確定 → 出荷準備 → 発送
```

各ステップでメール通知が届き、マイページでも進捗を確認できます。

## 5. マイページ

### 5-1. 上部サマリ
- **現在のランク** + リベート率
- **今月の発注額** (仮確定 + 確定)
- **次ランクまで**の不足額 + 進捗バー

### 5-2. 発注履歴
- ステータスタブで絞り込み (リクエスト / 発注調整中 / 仮確定 / 確定 / キャンセル)
- 行クリックで**詳細モーダル**: 確定数量・掛け率・金額内訳・追跡番号
- 10 件ずつページ送り

### 5-3. 請求書
- 行クリックで**詳細モーダル**: 金額内訳・入金状況・残額
- **PDF をダウンロード** ボタン

### 5-4. その他
- **発注履歴 CSV**: 自分の全発注をダウンロード
- **通知履歴** へのリンク

## 6. プロフィール管理

ヘッダーの **プロフィール** から。なりすまし防止のため、項目ごとに変更方法が異なります。

| 項目 | 変更方法 |
|---|---|
| 担当者名・電話番号 | **その場で変更可** (編集して保存) |
| 会社名・屋号 / 登録住所 / メール | **変更不可** — お問い合わせフォームから本人確認のうえ弊社が対応 |
| **配送先住所** | **申請制** — 申請 → 弊社確認 → 承認後に反映 (下記) |
| パスワード | その場で変更可 |
| 宣誓書 | PDF アップロード (失効日は弊社が設定) |

### 配送先の変更申請

1. プロフィール → 配送先住所 → 「**配送先の変更を申請する**」
2. 新しい住所と変更理由を入力 → 申請
3. 受付メールが届き、画面に「⏳ 確認中」と表示
4. 弊社確認後 (通常 1〜2 営業日)、**承認**または**却下**の結果がメールで届きます
5. 承認されると配送先が自動で書き換わります

## 7. お問い合わせ・FAQ

- **FAQ**: ヘッダーの FAQ からカテゴリ別のよくある質問を確認
- **お問い合わせ**: 件名・カテゴリ・関連商品 (任意)・本文を入力して送信
  - 担当者の返信はメール通知 + システム内のスレッドで確認できます
  - ステータス: 新規 → 対応中 → 解決済み

## 8. 通知履歴

ヘッダーの **通知** から、過去に送信された通知メールの履歴を確認できます (発注確認・請求書発行・ランク変動・変更申請の結果など)。

## 9. ランク制度

| ランク | 月次発注額 (昇格基準) | リベート還付率 |
|---|---|---|
| プラチナ | ¥1,000,000 以上 | 10% |
| ゴールド | ¥500,000 以上 | 7% |
| シルバー | ¥200,000 以上 | 5% |
| ブロンズ | ¥100,000 以上 | 3% |
| スタンダード | — | 0% |

- **昇格**: 基準を満たすと翌月 1 日に自動昇格
- **降格**: 昇格基準の 50% を下回ると 1 ヶ月の猶予後に 1 ランク降格
- リベートは請求書発行時に自動で差し引かれます

## 10. トラブルシュート

| 症状 | 対処 |
|---|---|
| ログインできない | 「パスワードを忘れた方」から再設定。解決しない場合は担当者へ |
| 認証メールが届かない | 迷惑メールフォルダを確認。**「迷惑メールではない」を押してから**リンクをクリック |
| リンクが無効と表示される | リンクは 1 回のみ有効。「再設定リンクを送り直す」から再発行 |
| 商品が表示されない | 締切超過・在庫切れ・非公開の可能性。検索条件もリセットして確認 |
| 「発注可能数を超えています」 | 在庫不足。商品カードの「残 N BOX」を確認 |
| 「在庫変動あり」で送信できない | カート投入後に在庫が減少。数量を減らすか商品を削除 |
| 請求書 PDF が出ない | 弊社で PDF 未生成。担当者にご連絡ください |
| その他 | お問い合わせフォームからご連絡ください |
