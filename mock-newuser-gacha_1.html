1. 概要・表示ロジック

ガチャ一覧（/ ポケモンタブ等）の最上部に「新規会員登録者限定エリア」を挿入する。エリアは対象ガチャ（ユーザー条件=新規会員登録のオリパ）を内包し、条件を満たさない場合はエリアごと非表示にする。
状態表示備考
非ログイン表示（全員）カウントダウンの代わりに「登録後N時間限定」の静的表記＋新規登録CTAボタンを表示
ログイン済・期間内表示残り時間カウントダウン表示。期限 = sms_verified_at + display_hours(h)、残り = 期限 − now（1秒間隔更新、HH:MM:SS）
ログイン済・期間外／既存ユーザー非表示エリアDOMごと出力しない（サーバー側判定推奨。CSS切替のみは不可）
期間中に期限到達非表示化カウントダウン0到達でエリアをフェードアウト→リロード時は非表示
時間数字（「N時間限定」等の文言内・カウントダウン初期値）はすべて管理画面の display_hours から動的描画し、文言にハードコードしない。文言自体は仮のため、テキストはCMS/定数で差し替え可能な実装を推奨。

2. データ（管理画面 → API）

フィールド型内容
user_conditionenumnone（指定なし） / new_user（新規会員登録）。既存「ユーザー条件」プルダウンに選択肢追加
display_hoursintuser_condition = new_user のとき必須。1〜8760（時間）。プリセット 24 / 72 / 168 はUIショートカット
sms_verified_atdatetimeユーザー側。SMS認証完了時刻（判定起点）
表示判定（サーバー側）：user_condition == 'new_user' のオリパは、未ログイン OR now < sms_verified_at + display_hours のときのみレスポンスに含める。

6. カウントダウンJS（参考実装）

countdown.js（参考）
// expiresAt = sms_verified_at + display_hours（サーバーから期限ISO文字列で受け取る想定）
function startCountdown(el, expiresAt, onExpire){
  const tick = () => {
    const remain = Math.floor((new Date(expiresAt) - Date.now()) / 1000);
    if (remain <= 0){ clearInterval(id); onExpire(); return; }
    const h = String(Math.floor(remain / 3600)).padStart(2, '0');
    const m = String(Math.floor(remain % 3600 / 60)).padStart(2, '0');
    const s = String(remain % 60).padStart(2, '0');
    el.textContent = `${h}:${m}:${s}`;
  };
  tick();
  const id = setInterval(tick, 1000);
}
// onExpire: エリアをフェードアウトして非表示（再取得時はサーバー側で除外される）

7. 補足

・文言（バッジ・タイトル・サブ・CTA・注記・ガチャ名）はすべて仮テキスト（修正余地あり）。実装は文言をハードコードせず差し替え可能にすること。
・エリア内のガチャカード・1/10ガチャボタン等は既存コンポーネントをそのまま流用（本仕様の対象外）。
・期限判定はサーバー時刻基準。クライアント時計のズレ対策として、期限はサーバーから絶対時刻（ISO8601）で返す。
